## Why It Surfaces

For each number in `[L, R]`, check whether any digit repeats. If no digit repeats, include it in the count.

## Worked Example

- `L = 10, R = 12` -> `2` (`10`, `12`)
- `L = 1, R = 100` -> `90`

## Reference Implementations

<ExamplePair>

```js
function totalNumbersWithNoRepeatedDigitsInARange(L, R) {
  if (!Number.isInteger(L) || !Number.isInteger(R)) {
    throw new TypeError('Expected integer bounds');
  }
  if (L > R) {
    return 0;
  }

  const hasUniqueDigits = (value) => {
    if (value < 0) {
      value = -value;
    }
    if (value < 10) {
      return true;
    }

    const seen = new Set();
    let n = value;
    while (n > 0) {
      const digit = n % 10;
      if (seen.has(digit)) {
        return false;
      }
      seen.add(digit);
      n = Math.floor(n / 10);
    }
    return true;
  };

  let count = 0;
  for (let x = L; x <= R; x += 1) {
    if (hasUniqueDigits(x)) {
      count += 1;
    }
  }
  return count;
}
```
