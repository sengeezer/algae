## Why It Surfaces

This prompt is a good follow-up to correlation alone because it asks for both interpretation and prediction. Once the running sums are available, you can compute Pearson's `r`, the regression slope, and the intercept without revisiting the data.

## Worked Example

For `X = [1, 2, 3, 4, 5]` and `Y = [2, 4, 6, 8, 10]`:

- the correlation coefficient is `1`
- the regression slope is `2`
- the intercept is `0`

So the best-fit line is `Y = 2X`.

```js
function correlationAndRegression(xValues, yValues) {
  if (!Array.isArray(xValues) || !Array.isArray(yValues) || xValues.length !== yValues.length) {
    throw new RangeError('Expected two arrays of equal length');
  }

  if (xValues.length < 2) {
    throw new RangeError('Expected at least two paired observations');
  }

  let sumX = 0;
  let sumY = 0;
  let sumXY = 0;
  let sumX2 = 0;
  let sumY2 = 0;

  for (let index = 0; index < xValues.length; index += 1) {
    const x = xValues[index];
    const y = yValues[index];

    if (
      typeof x !== 'number' ||
      !Number.isFinite(x) ||
      typeof y !== 'number' ||
      !Number.isFinite(y)
    ) {
      throw new TypeError('All values must be finite numbers');
    }

    sumX += x;
    sumY += y;
    sumXY += x * y;
    sumX2 += x * x;
    sumY2 += y * y;
  }

  const n = xValues.length;
  const covarianceFactor = n * sumXY - sumX * sumY;
  const xVarianceFactor = n * sumX2 - sumX * sumX;
  const yVarianceFactor = n * sumY2 - sumY * sumY;

  if (xVarianceFactor === 0 || yVarianceFactor === 0) {
    throw new RangeError('Correlation and regression require non-zero variance in both arrays');
  }

  const correlationCoefficient = covarianceFactor / Math.sqrt(xVarianceFactor * yVarianceFactor);
  const slope = covarianceFactor / xVarianceFactor;
  const intercept = (sumY - slope * sumX) / n;

  return {
    correlationCoefficient,
    slope,
    intercept,
  };
}
```

## Common Pitfalls

- Computing regression without checking that the `X` values have non-zero variance.
- Mixing the slope formula with the correlation denominator.
- Treating a strong correlation as proof of a causal relationship.
