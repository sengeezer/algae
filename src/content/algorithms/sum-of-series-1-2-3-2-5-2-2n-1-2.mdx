## Why It Surfaces

The series of odd squares has a standard closed form:

$$
S_n = 1^2 + 3^2 + 5^2 + \cdots + (2n-1)^2 = \frac{n(2n-1)(2n+1)}{3}
$$

This yields constant-time evaluation.

## Worked Example

- For `n = 4`: `1 + 9 + 25 + 49 = 84`
- For `n = 10`: sum is `1330`

## Reference Implementations

<ExamplePair>

```js
function sumOfOddSquaresSeries(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError('Expected a non-negative integer n');
  }

  return (n * (2 * n - 1) * (2 * n + 1)) / 3;
}
```

```ts

}
```
