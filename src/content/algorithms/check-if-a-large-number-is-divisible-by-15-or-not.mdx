## Why It Surfaces

Because `15 = 3 * 5` and 3 and 5 are coprime, a number is divisible by 15 iff it is divisible by both 3 and 5.

For decimal strings:

- divisible by 5: last digit is `0` or `5`
- divisible by 3: sum of digits is divisible by 3

## Worked Example

- `31` ends with `1`, so it is not divisible by 5 and therefore not divisible by 15.
- A large value ending in `0` with digit sum divisible by 3 is divisible by 15.

## Reference Implementations

<ExamplePair>

```js
function checkIfALargeNumberIsDivisibleBy15OrNot(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  const last = normalized.charAt(normalized.length - 1);
  if (last !== '0' && last !== '5') {
    return false;
  }

  let digitSum = 0;
  for (const ch of normalized) {
    digitSum += ch.charCodeAt(0) - 48;
  }

  return digitSum % 3 === 0;
}
```
