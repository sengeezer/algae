## Why It Surfaces

The requested number is exactly the next lexicographic permutation of the digits.

1. Scan from right to find pivot index `i` where `digits[i] < digits[i + 1]`.
2. If none exists, answer is `Not Possible`.
3. Find smallest digit on right side greater than pivot.
4. Swap them, then reverse suffix from `i + 1` onward.

## Worked Example

- `"218765"` -> `"251678"`
- `"1234"` -> `"1243"`
- `"4321"` -> `"Not Possible"`

```js
function findNextGreaterNumberWithSameSetOfDigits(n) {
  if (typeof n !== 'string' || n.length === 0 || !/^\d+$/.test(n)) {
    throw new TypeError('Expected a non-empty string of digits');
  }
  if (n.length === 1) {
    return 'Not Possible';
  }

  const digits = n.split('');
  let i = digits.length - 2;

  while (i >= 0 && digits[i] >= digits[i + 1]) {
    i -= 1;
  }

  if (i < 0) {
    return 'Not Possible';
  }

  let j = digits.length - 1;
  while (digits[j] <= digits[i]) {
    j -= 1;
  }

  [digits[i], digits[j]] = [digits[j], digits[i]];

  let left = i + 1;
  let right = digits.length - 1;
  while (left < right) {
    [digits[left], digits[right]] = [digits[right], digits[left]];
    left += 1;
    right -= 1;
  }

  return digits.join('');
}
```

## Common Pitfalls

- Picking any greater successor instead of the smallest greater successor.
- Sorting suffix ascending when a reverse is enough.
- Returning number type and losing leading zeros.
