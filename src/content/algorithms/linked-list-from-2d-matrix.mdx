## Problem

Given a 2D matrix, construct a linked representation where each cell is converted into a node containing:
- `right` pointer to the next column cell
- `down` pointer to the next row cell

## Approach

1. Create a node for each matrix cell.
2. Store created nodes in a 2D helper array.
3. Link each node's `right` and `down` pointers to valid neighbors.
4. Return the node at the top-left as the head of the structure.

**Time Complexity**: O(R * C)
**Space Complexity**: O(R * C)

## Implementation

```javascript
class MatrixNode {
  constructor(data) {
    this.data = data;
    this.right = null;
    this.down = null;
  }
}

function buildLinkedMatrix(matrix) {
  const rows = matrix.length;
  if (rows === 0) return null;

  const cols = matrix[0].length;
  if (cols === 0) return null;

  const nodes = Array.from({ length: rows }, () => Array(cols).fill(null));

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      nodes[r][c] = new MatrixNode(matrix[r][c]);
    }
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      nodes[r][c].right = c + 1 < cols ? nodes[r][c + 1] : null;
      nodes[r][c].down = r + 1 < rows ? nodes[r + 1][c] : null;
    }
  }

  return nodes[0][0];
}
```
