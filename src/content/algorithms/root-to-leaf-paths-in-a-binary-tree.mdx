## Problem

Given a binary tree, return all root-to-leaf paths. Each path should be represented as a list of node values.

### Examples

**Example 1:**
```
Input:     
       1
      / \
     2   3

Output: ["1->2", "1->3"]
```

**Example 2:**
```
Input:     
       1
      /
     2
      \
       3

Output: ["1->2->3"]
```

## Approach

### DFS with Backtracking
1. Start from root with empty path
2. Add current node to path
3. If leaf node, add complete path to result
4. Recursively visit left and right subtrees
5. Backtrack by removing current node from path

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Get all root-to-leaf paths as strings
 * Time: O(n), Space: O(h)
 */
function binaryTreePaths(root) {
  const result = [];

  function dfs(node, path) {
    if (node === null) return;

    // Add current node to path
    path.push(node.val);

    // Check if leaf node
    if (node.left === null && node.right === null) {
      result.push(path.join("->"));
    } else {
      dfs(node.left, path);
      dfs(node.right, path);
    }

    // Backtrack
    path.pop();
  }

  dfs(root, []);
  return result;
}

/**
 * Get all root-to-leaf paths as arrays
 * Time: O(n), Space: O(h)
 */
function binaryTreePathsArray(root) {
  const result = [];

  function dfs(node, path) {
    if (node === null) return;

    path.push(node.val);

    if (node.left === null && node.right === null) {
      result.push([...path]);
    } else {
      dfs(node.left, path);
      dfs(node.right, path);
    }

    path.pop();
  }

  dfs(root, []);
  return result;
}

/**
 * Collect paths with custom node processing
 * Time: O(n), Space: O(h)
 */
function binaryTreePathsCustom(root, processNode = null) {
  const result = [];

  function dfs(node, path) {
    if (node === null) return;

    path.push(processNode ? processNode(node) : node.val);

    if (node.left === null && node.right === null) {
      result.push([...path]);
    } else {
      dfs(node.left, path);
      dfs(node.right, path);
    }

    path.pop();
  }

  dfs(root, []);
  return result;
}
```

## Key Properties

- **Leaf Definition:** Both left and right children are null
- **Backtracking:** Critical to maintain correct path state
- **String Format:** Can represent paths as string or array

## Complexity Analysis

- **Time:** O(n) - visit each node once, O(n) string construction
- **Space:** O(h) - recursion depth, O(n) for storing all paths
