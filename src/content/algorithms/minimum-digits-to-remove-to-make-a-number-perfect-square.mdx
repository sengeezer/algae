## Why It Surfaces

The direct strategy is to enumerate all subsequences (via bitmasks), keep only valid numeric forms (no leading zero), and choose the perfect-square subsequence with the maximum length. The minimum removals are then:

`originalLength - bestSquareLength`

## Worked Example

- Input `8314` can form square subsequence `81`, so removals are `2`.
- Input `57` has no valid perfect-square subsequence, so answer is `-1`.

function minimumDigitsToRemoveToMakeAPerfectSquare(value) {
  const digits = String(value).trim();
  if (!/^\d+$/.test(digits)) {
    throw new TypeError('Expected a non-empty decimal digit string');
  }

  const n = digits.length;
  let best = null;

  const isPerfectSquare = (num) => {
    const root = Math.floor(Math.sqrt(num));
    return root * root === num;
  };

  for (let mask = 1; mask < (1 << n); mask += 1) {
    let candidate = '';
    for (let i = 0; i < n; i += 1) {
      if ((mask >> i) & 1) {
        candidate += digits[i];
      }
    }

    if (candidate[0] === '0') {
      continue;
    }

    const num = Number(candidate);
    if (!Number.isSafeInteger(num)) {
      continue;
    }

    if (isPerfectSquare(num)) {
      if (best === null || candidate.length > best.length) {
        best = candidate;
      }
    }
  }

  if (best === null) {
    return -1;
  }

  return {
    square: best,
    removedDigits: n - best.length,
  };
}

## Common Pitfalls

- Allowing leading-zero subsequences.
- Accepting any square instead of maximizing kept length.
- Forgetting to handle the no-solution case.
