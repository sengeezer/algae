## Why It Surfaces

Wilson's theorem is the rare interview theorem that gives an exact primality characterization instead of only a heuristic or a fast filter. It usually appears when the interviewer wants you to connect modular arithmetic, factorials, and prime structure rather than optimize raw runtime.

## Worked Example

For `n = 5`, the modular factorial is `(5 - 1)! = 24`, and `24 % 5 = 4`, which is the same as `-1 mod 5`. That satisfies Wilson's theorem, so `5` is prime.

For `n = 4`, `(4 - 1)! = 6`, and `6 % 4 = 2`, not `3`, so the theorem fails and `4` is composite.

```js
function wilsonsTheoremRemainder(value) {
  if (!Number.isInteger(value) || value < 1) {
    throw new RangeError('Value must be a positive integer');
  }

  if (value === 1) {
    return 0;
  }

  let remainder = 1;
  for (let factor = 2; factor < value; factor += 1) {
    remainder = (remainder * factor) % value;
  }

  return remainder;
}

function isPrimeByWilsonsTheorem(value) {
  if (!Number.isInteger(value) || value < 1) {
    throw new RangeError('Value must be a positive integer');
  }

  if (value === 1) {
    return false;
  }

  return wilsonsTheoremRemainder(value) === value - 1;
}

console.assert(isPrimeByWilsonsTheorem(2) === true, '2 should be prime');
console.assert(wilsonsTheoremRemainder(5) === 4, '4! mod 5 should be 4');
console.assert(isPrimeByWilsonsTheorem(5) === true, '5 should be prime');
console.assert(isPrimeByWilsonsTheorem(4) === false, '4 should be composite');
console.assert(isPrimeByWilsonsTheorem(9) === false, '9 should be composite');
```

## Follow-up Questions

- Compare Wilson's theorem with Fermat and Lucas style primality tests.
- Explain why multiplying modulo `n` avoids building the huge factorial explicitly.
- Return the modular remainder itself for a batch of small candidate inputs.

## Common Pitfalls

- Forgetting that `1` is not prime even though the theorem statement only applies for `n > 1`.
- Computing the full factorial instead of reducing modulo `n` at each multiplication.
- Treating Wilson's theorem as a practical large-input prime test instead of a theoretical characterization.
