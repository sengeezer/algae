## Why It Surfaces

Twin primes are the simplest fixed-gap prime pattern: gap-2 prime pairs. Once the prompt asks you to list or count them up to a limit, the right move is to precompute primality once and then scan for pairs `[p, p + 2]`.

## Worked Example

Up to `20`, the twin prime pairs are `[3, 5]`, `[5, 7]`, `[11, 13]`, and `[17, 19]`. The pair `[9, 11]` fails because only one side is prime, and `[7, 13]` fails because the gap is too large.

function sieve(limit) {
  const isPrime = new Array(limit + 1).fill(true);

  if (limit >= 0) {
    isPrime[0] = false;
  }

  if (limit >= 1) {
    isPrime[1] = false;
  }

  for (let value = 2; value * value <= limit; value += 1) {
    if (!isPrime[value]) {
      continue;
    }

    for (let multiple = value * value; multiple <= limit; multiple += value) {
      isPrime[multiple] = false;
    }
  }

  return isPrime;
}

function twinPrimePairs(limit) {
  if (!Number.isInteger(limit) || limit < 3) {
    return [];
  }

  const isPrime = sieve(limit);
  const pairs = [];

  for (let value = 3; value + 2 <= limit; value += 1) {
    if (isPrime[value] && isPrime[value + 2]) {
      pairs.push([value, value + 2]);
    }
  }

  return pairs;
}

console.assert(JSON.stringify(twinPrimePairs(4)) === JSON.stringify([]), 'Twin primes up to 4');

## Follow-up Questions

- Count twin prime pairs instead of returning the pairs themselves.
- Check whether one proposed pair is twin-prime without enumerating everything below it.
- Compare twin prime pairs with cousin primes or prime triplets.

## Common Pitfalls

- Treating any two numbers with difference `2` as twin primes without checking primality on both sides.
- Confusing twin primes with coprime numbers, which only require gcd `1`.
- Running trial division from scratch for every candidate pair instead of sieving once.
