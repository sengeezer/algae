## Why It Surfaces

`log*(n)` is the number of times logarithm must be applied until the result is at most 1.

Using base `b`:

- if `n <= 1`, answer is `0`
- otherwise, answer is `1 + log*(log_b(n))`

## Worked Example

- `n = 100`, `base = 5` -> `2`
  - `log_5(100) ≈ 2.86`
  - `log_5(2.86) < 1`

## Reference Implementations

<ExamplePair>

```js
function iteratedLogarithmLogStarN(n, base) {
  if (!Number.isFinite(n) || !Number.isFinite(base) || n < 0 || base <= 1) {
    throw new RangeError('Expected n >= 0 and base > 1');
  }

  let count = 0;
  let value = n;
  while (value > 1) {
    value = Math.log(value) / Math.log(base);
    count += 1;
  }

  return count;
}
```

## Common Pitfalls

- Allowing base `<= 1`.
- Confusing `log*(n)` with `log(log(n))`.
- Using integer truncation on intermediate logarithm values.
