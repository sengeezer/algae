## Why It Surfaces

This prompt checks whether you know the divisibility shortcut for `4`. In base `10`, every higher place beyond the last two contributes a multiple of `100`, so only the two-digit suffix controls divisibility by `4`.

## Worked Example

- `1124` ends with `24`, and `24 % 4 = 0`, so it is divisible by `4`.
- `1234567589333862` ends with `62`, and `62 % 4 = 2`, so it is not divisible by `4`.

```js
function checkIfALargeNumberIsDivisibleBy4OrNot(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  if (normalized.length === 1) {
    return (normalized.charCodeAt(0) - 48) % 4 === 0;
  }

  const tens = normalized.charCodeAt(normalized.length - 2) - 48;
  const ones = normalized.charCodeAt(normalized.length - 1) - 48;
  return (tens * 10 + ones) % 4 === 0;
}
```
