## Problem

Given building heights from left to right, count how many buildings can see the sun from the left side.

## Approach

Track the maximum height seen so far. A building is visible if its height is greater than this maximum.

**Time Complexity**: O(n)
**Space Complexity**: O(1)

## Implementation

```javascript
function countBuildingsFacingSun(heights) {
  if (heights.length === 0) return 0;

  let visible = 0;
  let maxHeight = -Infinity;

  for (const h of heights) {
    if (h > maxHeight) {
      visible++;
      maxHeight = h;
    }
  }

  return visible;
}
```
