## Problem

For each array element, find the next greater element (to the right), then from that position find its next smaller element (to the right). Return that value or `-1`.

## Approach

1. Compute `ngeIndex[i]` with a decreasing stack.
2. Compute `nseIndex[i]` with an increasing stack.
3. Answer for `i` is `arr[nseIndex[ngeIndex[i]]]` when both indices exist.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function nextSmallerOfNextGreater(arr) {
  const n = arr.length;
  const nge = new Array(n).fill(-1);
  const nse = new Array(n).fill(-1);
  const dec = [];
  const inc = [];

  for (let i = n - 1; i >= 0; i--) {
    while (dec.length && arr[dec[dec.length - 1]] <= arr[i]) dec.pop();
    nge[i] = dec.length ? dec[dec.length - 1] : -1;
    dec.push(i);
  }

  for (let i = n - 1; i >= 0; i--) {
    while (inc.length && arr[inc[inc.length - 1]] >= arr[i]) inc.pop();
    nse[i] = inc.length ? inc[inc.length - 1] : -1;
    inc.push(i);
  }

  const ans = new Array(n).fill(-1);
  for (let i = 0; i < n; i++) {
    const g = nge[i];
    if (g === -1) continue;
    const s = nse[g];
    ans[i] = s === -1 ? -1 : arr[s];
  }

  return ans;
}
```
