## Why It Surfaces

The divisibility by 12 test is composite: `12 = 3 * 4` with coprime factors. So a number is divisible by 12 iff it is divisible by both 3 and 4.

## Worked Example

- `2112` has digit sum `6` (divisible by 3) and last two digits `12` (divisible by 4), so it is divisible by 12.
- `1234567589333862` has last two digits `62`, not divisible by 4, so it is not divisible by 12.

```js
function divisibilityBy12ForALargeNumber(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  const lastDigit = normalized.charCodeAt(normalized.length - 1) - 48;
  const secondLastDigit = normalized.length > 1 ? normalized.charCodeAt(normalized.length - 2) - 48 : 0;
  const lastTwoDigits = secondLastDigit * 10 + lastDigit;
  if (lastTwoDigits % 4 !== 0) {
    return false;
  }

  let digitSum = 0;
  for (const digit of normalized) {
    digitSum += digit.charCodeAt(0) - 48;
  }

  return digitSum % 3 === 0;
}
```

## Common Pitfalls

- Checking only one of the two required factors.
- Parsing the full number into fixed-width types and risking overflow.
- Mishandling one-digit inputs while extracting the last two-digit suffix.
