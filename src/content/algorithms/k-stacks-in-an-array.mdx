## Problem

Implement `k` stacks in one array of size `n` with O(1) push and pop.

## Approach

Use:
- `arr` for values,
- `top[k]` for each stack top,
- `next[n]` for both free-list chaining and per-stack links,
- `free` index for first free slot.

**Time Complexity**: O(1) per operation
**Space Complexity**: O(n + k)

## Implementation

```javascript
class KStacks {
  constructor(k, n) {
    this.k = k;
    this.n = n;
    this.arr = new Array(n);
    this.top = new Array(k).fill(-1);
    this.next = new Array(n);
    for (let i = 0; i < n - 1; i++) this.next[i] = i + 1;
    this.next[n - 1] = -1;
    this.free = 0;
  }

  push(value, sn) {
    if (this.free === -1) throw new Error('Overflow');

    const i = this.free;
    this.free = this.next[i];

    this.next[i] = this.top[sn];
    this.top[sn] = i;
    this.arr[i] = value;
  }

  pop(sn) {
    if (this.top[sn] === -1) throw new Error('Underflow');

    const i = this.top[sn];
    this.top[sn] = this.next[i];

    this.next[i] = this.free;
    this.free = i;

    return this.arr[i];
  }
}
```
