## Problem

Insert a value into a sorted doubly linked list so that the list remains sorted.

## Approach

Traverse until the first node with value greater than or equal to `value`. Insert before it. If no such node exists, append at tail.

**Time Complexity**: O(n)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.prev = null;
    this.next = null;
  }
}

function insertInSortedWayInDoublyLinkedList(head, value) {
  const node = new Node(value);

  if (head === null) {
    return node;
  }

  if (value <= head.data) {
    node.next = head;
    head.prev = node;
    return node;
  }

  let current = head;
  while (current.next !== null && current.next.data < value) {
    current = current.next;
  }

  node.next = current.next;
  node.prev = current;
  current.next = node;

  if (node.next !== null) {
    node.next.prev = node;
  }

  return head;
}
```
