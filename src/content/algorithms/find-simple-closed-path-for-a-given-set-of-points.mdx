## Why It Surfaces

This problem tests geometric ordering rather than hull extraction. The standard pattern is to anchor at the bottom-most point, then sort all remaining points by their polar direction around that anchor so traversing in order yields a simple closed path.

## Worked Example

For points `(0, 3)`, `(1, 1)`, `(2, 2)`, `(4, 4)`, `(0, 0)`, `(1, 2)`, `(3, 1)`, `(3, 3)`, one valid non-crossing order is:

`(0, 0) -> (3, 1) -> (1, 1) -> (2, 2) -> (3, 3) -> (4, 4) -> (1, 2) -> (0, 3)`

```js
function findSimpleClosedPathForAGivenSetOfPoints(points) {
  if (!Array.isArray(points) || points.length < 3) {
    throw new RangeError("At least three points are required");
  }

  const uniquePoints = [...new Map(points.map((point) => [`${point.x},${point.y}`, point])).values()];
  if (uniquePoints.length < 3) {
    throw new RangeError("At least three distinct points are required");
  }

  const anchor = uniquePoints.reduce((best, point) =>
    point.y < best.y || (point.y === best.y && point.x < best.x) ? point : best,
  uniquePoints[0]);

  function squaredDistance(first, second) {
    return (first.x - second.x) ** 2 + (first.y - second.y) ** 2;
  }

  const remainder = uniquePoints.filter((point) => point !== anchor);
  remainder.sort((left, right) => {
    const leftAngle = Math.atan2(left.y - anchor.y, left.x - anchor.x);
    const rightAngle = Math.atan2(right.y - anchor.y, right.x - anchor.x);
    if (leftAngle !== rightAngle) {
      return leftAngle - rightAngle;
    }
    return squaredDistance(anchor, left) - squaredDistance(anchor, right);
  });

  return [anchor, ...remainder];
}
```

## Follow-up Questions

- Why does radial sorting around one pivot avoid edge crossings in this construction?
- How does this differ from returning a convex hull?
- What changes if two points are identical or many points are collinear from the anchor?

## Common Pitfalls

- Picking the wrong anchor when multiple points share the lowest y-coordinate.
- Ignoring tie breaks for equal polar angles.
- Assuming this always returns the convex hull instead of a simple closed path.
