## Why It Surfaces

Confidence intervals are the shortest path from descriptive statistics into statistical inference. The implementation is small, but it still tests whether you keep the confidence level, critical value, standard error, and margin of error conceptually separate.

## Worked Example

Suppose a sample has mean `4.63`, standard deviation `0.54`, sample size `50`, and a `95%` z-critical value of `1.96`.

- standard error: `0.54 / sqrt(50) ≈ 0.07637`
- margin of error: `1.96 * 0.07637 ≈ 0.14969`
- confidence interval: `4.63 +/- 0.14969 ≈ [4.4803, 4.7797]`

## Reference Implementations

<ExamplePair>

```js
function confidenceInterval(sampleMean, standardDeviation, sampleSize, criticalValue) {
  if (typeof sampleMean !== 'number' || !Number.isFinite(sampleMean)) {
    throw new TypeError('sampleMean must be a finite number');
  }

  if (
    typeof standardDeviation !== 'number' ||
    !Number.isFinite(standardDeviation) ||
    standardDeviation < 0
  ) {
    throw new RangeError('standardDeviation must be a non-negative finite number');
  }

  if (!Number.isInteger(sampleSize) || sampleSize <= 0) {
    throw new RangeError('sampleSize must be a positive integer');
  }

  if (typeof criticalValue !== 'number' || !Number.isFinite(criticalValue) || criticalValue <= 0) {
    throw new RangeError('criticalValue must be a positive finite number');
  }

  const standardError = standardDeviation / Math.sqrt(sampleSize);
  const marginOfError = criticalValue * standardError;

  return {
    marginOfError,
    lowerBound: sampleMean - marginOfError,
    upperBound: sampleMean + marginOfError,
  };
}
```

  const marginOfError = criticalValue * standardError;

  return {
    marginOfError,
    lowerBound: sampleMean - marginOfError,
    upperBound: sampleMean + marginOfError,

}

## Common Pitfalls

- Confusing the confidence level (for example `95%`) with the critical value (`1.96`).
- Forgetting the square root in the standard error.
- Using variance where the formula expects standard deviation.
