## Why It Surfaces

Farey-sequence questions are about enumeration rather than approximation. The task is to list every reduced fraction between `0 / 1` and `1 / 1` whose denominator stays within an order bound, while preserving sorted order without sorting a large candidate set afterward.

## Worked Example

For order `4`, the Farey sequence is `0 / 1`, `1 / 4`, `1 / 3`, `1 / 2`, `2 / 3`, `3 / 4`, and `1 / 1`. Each term is in lowest terms, and every denominator is at most `4`.

```js
function fareySequence(order) {
  if (!Number.isInteger(order) || order < 1) {
    throw new RangeError('Order must be a positive integer');
  }

  const sequence = [{ numerator: 0, denominator: 1 }];

  let a = 0;
  let b = 1;
  let c = 1;
  let d = order;

  sequence.push({ numerator: c, denominator: d });

  while (!(c === 1 && d === 1)) {
    const step = Math.floor((order + b) / d);
    const nextNumerator = step * c - a;
    const nextDenominator = step * d - b;

    a = c;
    b = d;
    c = nextNumerator;
    d = nextDenominator;

    sequence.push({ numerator: c, denominator: d });
  }

  return sequence;
}

console.assert(
  JSON.stringify(fareySequence(1)) === JSON.stringify([
    { numerator: 0, denominator: 1 },
    { numerator: 1, denominator: 1 },
  ]),
  'Farey sequence of order 1'
);

console.assert(
  JSON.stringify(fareySequence(4)) === JSON.stringify([
    { numerator: 0, denominator: 1 },
    { numerator: 1, denominator: 4 },
    { numerator: 1, denominator: 3 },
    { numerator: 1, denominator: 2 },
    { numerator: 2, denominator: 3 },
```

## Follow-up Questions

## Common Pitfalls

- Generating every numerator-denominator pair and sorting afterward instead of using the recurrence.
- Forgetting that every term must already be in reduced form.
- Treating Farey-sequence generation as the same task as approximating one decimal target.
