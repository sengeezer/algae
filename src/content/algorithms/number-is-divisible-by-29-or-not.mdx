## Why It Surfaces

A useful reduction for 29 is:

1. Split number as `10a + b` where `b` is last digit.
2. Replace it with `a + 3b`.
3. Repeat until the value is small.

This preserves divisibility by 29. If the reduced value is divisible by 29, the original number is too.

## Worked Example

- For `348`: `34 + 3*8 = 58`, and `58` is divisible by 29, so `348` is divisible by 29.
- `363927598` reduces to a non-multiple of 29, so it is not divisible by 29.

function numberIsDivisibleBy29OrNot(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  // Keep values small and exact using BigInt through the reduction process.
  let n = BigInt(normalized);
  while (n >= 100n) {
    const lastDigit = n % 10n;
    n = n / 10n;
    n += 3n * lastDigit;
  }

  return n % 29n === 0n;
}
