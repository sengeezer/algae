## Why It Surfaces

This is a composite divisibility rule question. Because `6 = 2 * 3` and `2` and `3` are coprime, a number is divisible by `6` iff it is divisible by both `2` and `3`.

## Worked Example

- `2112` ends in `2` (even) and has digit sum `2 + 1 + 1 + 2 = 6` (divisible by `3`), so it is divisible by `6`.
- `1124` ends in `4` (even) but has digit sum `8` (not divisible by `3`), so it is not divisible by `6`.

```js
function checkIfALargeNumberIsDivisibleBy6OrNot(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  const lastDigit = normalized.charCodeAt(normalized.length - 1) - 48;
  if (lastDigit % 2 !== 0) {
    return false;
  }

  let digitSum = 0;
  for (const digit of normalized) {
    digitSum += digit.charCodeAt(0) - 48;
  }

  return digitSum % 3 === 0;
}
```
