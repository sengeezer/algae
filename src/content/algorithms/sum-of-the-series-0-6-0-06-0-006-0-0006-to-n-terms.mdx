## Why It Surfaces

This is a geometric progression with first term $a = 0.6$ and ratio $r = 0.1$.

$$
S_n = a \cdot \frac{1-r^n}{1-r} = 0.6 \cdot \frac{1-0.1^n}{0.9} = \frac{2}{3}(1-10^{-n})
$$

## Worked Example

- `n = 2` gives `0.66`
- `n = 3` gives `0.666`

## Reference Implementations

<ExamplePair>

```js
function sumOfTheSeries0Point6ToNTerms(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError('Expected a non-negative integer n');
  }

  return (2 / 3) * (1 - 1 / Math.pow(10, n));
}
```
