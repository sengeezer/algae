## Problem

Given two singly linked lists, determine whether the second list appears as a contiguous sublist inside the first list.

## Approach

1. If pattern list is empty, return `true`.
2. For each node in the main list, attempt to match the entire pattern list.
3. On mismatch, restart matching from the next main-list node.
4. If all pattern nodes match contiguously, return `true`; otherwise `false`.

**Time Complexity**: O(N * M)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function isSublist(mainHead, patternHead) {
  if (patternHead === null) return true;
  if (mainHead === null) return false;

  let currentMain = mainHead;

  while (currentMain !== null) {
    let pMain = currentMain;
    let pPattern = patternHead;

    while (pMain !== null && pPattern !== null && pMain.data === pPattern.data) {
      pMain = pMain.next;
      pPattern = pPattern.next;
    }

    if (pPattern === null) {
      return true;
    }

    currentMain = currentMain.next;
  }

  return false;
}
```
