## Why It Surfaces

This sequence appears as a constructive pattern problem. Starting with `1, 1`, for each considered element you append:

1. the sum of the considered element and its predecessor
2. the considered element itself

and continue until `n` terms are produced.

- First 15 terms: `1 1 2 1 3 2 3 1 4 3 5 2 5 3 4`

## Reference Implementations

<ExamplePair>

```js
function sternBrocotSequence(count) {
  if (!Number.isInteger(count) || count <= 0) {
    throw new RangeError('Expected a positive integer count');
  }

  if (count === 1) {
    return [1];
  }

  const sequence = [1, 1];
  for (let i = 1; sequence.length < count; i += 1) {
    const considered = sequence[i];
    const precedent = sequence[i - 1];

    sequence.push(considered + precedent);
    if (sequence.length < count) {
      sequence.push(considered);
    }
  }

  return sequence;
}
```

## Common Pitfalls

- Mishandling the initial seed for `count = 1`.
- Appending past the requested number of terms.
- Off-by-one errors in predecessor indexing.
