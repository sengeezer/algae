## Problem

Implement stack (`push`, `pop`, `top`) using only queue operations.

## Approach

For `push`, enqueue new element to `q2`, move all from `q1` to `q2`, then swap queues. This keeps stack top at `q1.front()`.

**Time Complexity**: Push O(n), Pop O(1), Top O(1)
**Space Complexity**: O(n)

## Implementation

```javascript
class StackUsingQueues {
  constructor() {
    this.q1 = [];
    this.q2 = [];
  }

  push(x) {
    this.q2.push(x);
    while (this.q1.length > 0) {
      this.q2.push(this.q1.shift());
    }
    [this.q1, this.q2] = [this.q2, this.q1];
  }

  pop() {
    if (this.q1.length === 0) return null;
    return this.q1.shift();
  }

  top() {
    if (this.q1.length === 0) return null;
    return this.q1[0];
  }
}
```

```typescript
class StackUsingQueues {
  private q1: number[] = [];
  private q2: number[] = [];

  push(x: number): void {
    this.q2.push(x);
    while (this.q1.length > 0) {
      this.q2.push(this.q1.shift()!);
    }
    [this.q1, this.q2] = [this.q2, this.q1];
  }

  pop(): number | null {
    if (this.q1.length === 0) return null;
    return this.q1.shift()!;
  }

  top(): number | null {
    if (this.q1.length === 0) return null;
    return this.q1[0];
  }
}
```
