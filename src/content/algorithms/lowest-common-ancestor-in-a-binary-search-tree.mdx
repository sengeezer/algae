## Problem

Given a binary search tree and two nodes with values p and q, find the lowest common ancestor (LCA) of the two nodes.

### Examples

**Example 1:**
```
Input: 
       6
      / \
     2   8
    / \  / \
   0  4 7  9
    / \
   3   5

p = 2, q = 8
Output: 6
```

**Example 2:**
```
Input: 
       6
      / \
     2   8
    / \  / \
   0  4 7  9
    / \
   3   5

p = 2, q = 4
Output: 2 (node 2 is ancestor of 4)
```

## Approach

### BST Property-Based
Since BST has ordering property (left < root < right):
1. If both p and q are less than root, LCA is in left subtree
2. If both p and q are greater than root, LCA is in right subtree
3. Otherwise, root is the LCA

This exploits BST structure for O(log n) average performance.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Recursive approach using BST property
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) recursion depth
 */
function lowestCommonAncestor(root, p, q) {
  if (root === null) return null;

  if (p.val < root.val && q.val < root.val) {
    // Both in left subtree
    return lowestCommonAncestor(root.left, p, q);
  } else if (p.val > root.val && q.val > root.val) {
    // Both in right subtree
    return lowestCommonAncestor(root.right, p, q);
  } else {
    // Split or one is root
    return root;
  }
}

/**
 * Iterative approach
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function lowestCommonAncestorIterative(root, p, q) {
  let current = root;

  while (current !== null) {
    if (p.val < current.val && q.val < current.val) {
      current = current.left;
    } else if (p.val > current.val && q.val > current.val) {
      current = current.right;
    } else {
      // Found the split point or one equals current
      return current;
    }
  }

  return null;
}

/**
 * With value comparison instead of node comparison
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) or O(1)
 */
function lowestCommonAncestorByValue(root, pVal, qVal) {
  let current = root;

  while (current !== null) {
    if (pVal < current.val && qVal < current.val) {
      current = current.left;
    } else if (pVal > current.val && qVal > current.val) {
      current = current.right;
    } else {
      return current;
    }
  }

  return null;
}
```

## Key Properties

- **Split Point:** LCA is where paths to p and q diverge
- **BST Advantage:** Can prune half the tree at each step
- **General Tree:** General binary tree LCA requires visiting all nodes
- **Efficiency Gain:** O(log n) vs O(n) for unordered trees

## Complexity Analysis

- **Time:** 
  - Average: O(log n) for balanced tree
  - Worst: O(n) for skewed tree
- **Space:**
  - Recursive: O(h) for recursion depth
  - Iterative: O(1) constant space
