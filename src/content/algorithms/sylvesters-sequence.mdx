## Why It Surfaces

Sylvester's sequence starts at `2` and each next term is one more than the product of all previous terms. The GeeksforGeeks variant also highlights modulo handling for very large values.

## Worked Example

- First 6 terms: `2, 3, 7, 43, 1807, 3263443`
- For `N = 2`: `2, 3`

## Reference Implementations

<ExamplePair>

```js
function sylvestersSequence(count, mod = 1_000_000_007) {
  if (!Number.isInteger(count) || count <= 0) {
    throw new RangeError('Expected a positive integer count');
  }

  const result = [];
  let runningProduct = 1;
  let current = 2;

  for (let i = 0; i < count; i += 1) {
    result.push(current);
    runningProduct = (runningProduct * current) % mod;
    current = (runningProduct + 1) % mod;
  }

  return result;
}
```

## Common Pitfalls

- Forgetting to update running product before computing the next term.
- Integer overflow when not using modulo or big integers.
- Mis-initializing the first term as 1 instead of 2.
