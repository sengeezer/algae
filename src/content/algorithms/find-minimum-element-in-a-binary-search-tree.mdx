## Problem

Given a binary search tree, find and return the minimum value (leftmost node).

### Examples

**Example 1:**
```
Input: 
       4
      / \
     2   7
    / \
   1   3

Output: 1
```

**Example 2:**
```
Input: 
       10
        \
         20
        /  \
       15   30

Output: 10
```

**Example 3:**
```
Input: Single node
       5

Output: 5
```

## Approach

### Iterative
Traverse left from the root until reaching a node with no left child.

### Recursive
If left child exists, recursively find minimum in left subtree. Otherwise, current node is minimum.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Iterative approach to find minimum
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function findMin(root) {
  if (root === null) return null;

  let current = root;
  while (current.left !== null) {
    current = current.left;
  }

  return current.val;
}

/**
 * Recursive approach to find minimum
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) recursion depth
 */
function findMinRecursive(root) {
  if (root === null) return null;

  if (root.left === null) {
    return root.val;
  }

  return findMinRecursive(root.left);
}

/**
 * Get the entire minimum node (not just value)
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function findMinNode(root) {
  if (root === null) return null;

  let current = root;
  while (current.left !== null) {
    current = current.left;
  }

  return current;
}
```

## Key Properties

- **Always Left:** Minimum is always the leftmost reachable node
- **No Right Child Needed:** Minimum node may have a right subtree
- **In-order Predecessor:** Minimum in right subtree is successor to deletion

## Complexity Analysis

- **Time:** 
  - Average: O(log n) for balanced tree
  - Worst: O(n) for left-skewed tree
- **Space:**
  - Iterative: O(1) constant
  - Recursive: O(h) for recursion depth
