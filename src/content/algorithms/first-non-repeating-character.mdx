## Problem

For each prefix of a lowercase string stream, return the first character that has appeared exactly once so far, or `#` if none exists.

## Approach

Maintain a frequency array and a queue of candidate characters. Push new characters once, then pop from the front while the front is repeated.

**Time Complexity**: O(n)
**Space Complexity**: O(1)

## Implementation

```javascript
function firstNonRepeating(stream) {
  const counts = new Array(26).fill(0);
  const queue = [];
  const result = [];
  let head = 0;

  for (const ch of stream) {
    const index = ch.charCodeAt(0) - 97;
    counts[index] += 1;

    if (counts[index] === 1) {
      queue.push(ch);
    }

    while (head < queue.length && counts[queue[head].charCodeAt(0) - 97] > 1) {
      head += 1;
    }

    result.push(head < queue.length ? queue[head] : '#');
  }

  return result.join('');
}
```
