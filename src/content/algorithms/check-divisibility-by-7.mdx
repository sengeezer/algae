## Why It Surfaces

This checks whether you can preserve divisibility through transformations. For `n = 10a + b`, `n` is divisible by `7` iff `a - 2b` is divisible by `7`, so repeated reduction gives a small-value decision test.

## Worked Example

- `371`: `37 - 2*1 = 35`, then `3 - 2*5 = -7`, and `-7` is divisible by `7`, so `371` is divisible by `7`.
- `7673`: `767 - 2*3 = 761`, `76 - 2*1 = 74`, `7 - 2*4 = -1`, and `-1` is not divisible by `7`, so it is not divisible by `7`.

## Reference Implementations

<ExamplePair>

```js
function checkDivisibilityBy7(value) {
  if (!Number.isInteger(value)) {
    throw new TypeError("Expected an integer input");
  }

  let n = Math.abs(value);
  if (n === 0 || n === 7) {
    return true;
  }

  while (n >= 10) {
    const lastDigit = n % 10;
    n = Math.floor(n / 10) - 2 * lastDigit;
    n = Math.abs(n);
  }

  return n === 0 || n === 7;
}
```

- Stopping the loop too early before reaching a small decision value.
