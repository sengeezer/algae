## Problem

Given input sequence and target output sequence, determine whether the target can be produced using one auxiliary stack.

## Approach

Push input items one by one. After each push, pop while stack top matches the next needed target element.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function isStackPermutation(input, target) {
  const stack = [];
  let j = 0;

  for (const value of input) {
    stack.push(value);

    while (stack.length > 0 && j < target.length && stack[stack.length - 1] === target[j]) {
      stack.pop();
      j++;
    }
  }

  return j === target.length;
}
```
