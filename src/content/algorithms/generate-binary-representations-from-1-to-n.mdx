## Problem

Return the binary representations of all integers from `1` to `n` in order.

## Approach

Start with `1` in a queue. Repeatedly pop the front string, append it to the result, and enqueue its `0` and `1` children.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function generateBinaryRepresentations(n) {
  const queue = ['1'];
  const result = [];
  let head = 0;

  while (result.length < n) {
    const value = queue[head++];
    result.push(value);
    queue.push(`${value}0`);
    queue.push(`${value}1`);
  }

  return result;
}
```
