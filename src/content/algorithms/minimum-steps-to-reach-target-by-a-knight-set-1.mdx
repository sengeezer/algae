## Problem

Given a knight position and a target square on an `n x n` board, return the minimum number of moves required.

## Approach

Run BFS from the knight's start position. Each queue item stores the square and the distance so far.

**Time Complexity**: O(n^2)
**Space Complexity**: O(n^2)

## Implementation

```javascript
function minKnightSteps(boardSize, start, target) {
  const moves = [
    [-2, -1], [-2, 1], [-1, -2], [-1, 2],
    [1, -2], [1, 2], [2, -1], [2, 1],
  ];
  const visited = Array.from({ length: boardSize }, () => Array(boardSize).fill(false));
  const queue = [[start[0], start[1], 0]];
  let head = 0;

  visited[start[0]][start[1]] = true;

  while (head < queue.length) {
    const [row, col, distance] = queue[head++];

    if (row === target[0] && col === target[1]) {
      return distance;
    }

    for (const [dr, dc] of moves) {
      const nextRow = row + dr;
      const nextCol = col + dc;

      if (
        nextRow >= 0 && nextRow < boardSize &&
        nextCol >= 0 && nextCol < boardSize &&
        !visited[nextRow][nextCol]
      ) {
        visited[nextRow][nextCol] = true;
        queue.push([nextRow, nextCol, distance + 1]);
      }
    }
  }

  return -1;
}
```
