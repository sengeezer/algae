## Why It Surfaces

The sequence has a direct constructive pattern. If `term_k` is current term, then next term is:

`term_{k+1} = term_k * 10 + 2`

Add each generated term to a running total.

## Worked Example

- `n = 2` gives `2 + 22 = 24`
- `n = 3` gives `2 + 22 + 222 = 246`

## Reference Implementations

<ExamplePair>

```js
function sumOfTheSequence222(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError('Expected a non-negative integer n');
  }

  let sum = 0;
  let term = 0;

  for (let i = 0; i < n; i += 1) {
    term = term * 10 + 2;
    sum += term;
  }

  return sum;
}
```

## Common Pitfalls

- Initializing the first term incorrectly.
- Forgetting to update term before adding to sum.
- Assuming fixed-width integers always suffice.
