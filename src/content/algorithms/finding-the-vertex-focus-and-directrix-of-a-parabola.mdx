## Why It Surfaces

This problem appears when an interviewer wants algebra-to-geometry translation, not root solving. You extract the parabola's turning point and focal distance from coefficients, then express the directrix as a horizontal line.

## Worked Example

For `a = 5`, `b = 3`, `c = 2`, we get:

- Vertex: `(-0.3, 1.55)`
- Focus: `(-0.3, 1.6)`
- Directrix: `y = 1.5`

## Reference Implementations

<ExamplePair>

```js
function findingTheVertexFocusAndDirectrixOfAParabola(a, b, c) {
  if (!Number.isFinite(a) || !Number.isFinite(b) || !Number.isFinite(c) || a === 0) {
    throw new RangeError("Expected finite coefficients with a != 0 for y = ax^2 + bx + c");
  }

  const xVertex = -b / (2 * a);
  const yVertex = c - (b * b) / (4 * a);
  const focalOffset = 1 / (4 * a);
  const yFocus = yVertex + focalOffset;
  const directrixY = yVertex - focalOffset;

  return {
    vertex: { x: xVertex, y: yVertex },
    focus: { x: xVertex, y: yFocus },
    directrix: { type: "horizontal", y: directrixY },
  };
}
```

## Follow-up Questions

- How do these formulas change for a sideways parabola like `x = ay^2 + by + c`?
- Why is the focal offset exactly `1 / (4a)` in the vertical form?
- How do sign changes in `a` affect focus and directrix placement?

## Common Pitfalls

- Forgetting to reject `a = 0`, which is not a parabola.
- Mixing up `+ 1/(4a)` and `- 1/(4a)` between focus and directrix.
- Treating the directrix as a point instead of a line.
