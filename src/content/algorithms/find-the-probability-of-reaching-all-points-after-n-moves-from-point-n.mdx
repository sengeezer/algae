## Why It Surfaces

This is the distribution-valued version of a random walk. Instead of asking for one destination probability, the prompt asks for every point's probability after exactly `N` moves, so the natural state is a DP array over current position.

## Worked Example

For `N = 2` and left-move probability `0.5`, the walk starts at point `2` and makes exactly two `+1` or `-1` moves.

- Reaching point `0` requires two left moves: probability `0.25`
- Reaching point `2` requires one left and one right move in either order: probability `0.5`
- Reaching point `4` requires two right moves: probability `0.25`

So the final distribution over points `0..4` is `[0.25, 0, 0.5, 0, 0.25]`.

```js
function findTheProbabilityOfReachingAllPointsAfterNMovesFromPointN(moves, leftProbability) {
  if (!Number.isInteger(moves) || moves < 0) {
    throw new RangeError('moves must be a non-negative integer');
  }

  if (
    typeof leftProbability !== 'number' ||
    !Number.isFinite(leftProbability) ||
    leftProbability < 0 ||
    leftProbability > 1
  ) {
    throw new RangeError('leftProbability must be between 0 and 1');
  }

  const width = 2 * moves + 1;
  const rightProbability = 1 - leftProbability;
  let distribution = new Array(width).fill(0);
  distribution[moves] = 1;

  for (let step = 0; step < moves; step += 1) {
    const nextDistribution = new Array(width).fill(0);

    for (let index = 0; index < width; index += 1) {
      const currentProbability = distribution[index];

      if (currentProbability === 0) {
        continue;
      }

      if (index > 0) {
        nextDistribution[index - 1] += currentProbability * leftProbability;
      }

      if (index + 1 < width) {
        nextDistribution[index + 1] += currentProbability * rightProbability;
      }
    }

    distribution = nextDistribution;
  }

  return distribution;
}
```

## Follow-up Questions

- Compress the output to only reachable positions with the correct parity.
- Compute the probability of ending within a range instead of returning the whole distribution.
- Compare this DP with the corresponding binomial-coefficient closed form for one target point.

## Common Pitfalls

- Forgetting that the walk starts at point `N`, not at `0`.
- Mutating the current distribution in place and accidentally reusing same-step updates.
- Returning only one endpoint probability when the prompt asks for all points.
