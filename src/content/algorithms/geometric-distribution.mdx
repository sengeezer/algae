## Why It Surfaces

Geometric distribution is the clean model for waiting time until the first success. It looks similar to binomial at first glance, but the exponent belongs on the failures before the success, which is where most mistakes happen.

## Worked Example

If the probability of success on each attempt is `0.4`, the probability that the first success happens on trial `3` is:

`(1 - 0.4)^(3 - 1) * 0.4 = 0.6^2 * 0.4 = 0.144`

## Reference Implementations

<ExamplePair>

```js
function geometricDistribution(successProbability, trialNumber) {
  if (
    typeof successProbability !== 'number' ||
    !Number.isFinite(successProbability) ||
    successProbability < 0 ||
    successProbability > 1
  ) {
    throw new RangeError('successProbability must be between 0 and 1');
  }

  if (!Number.isInteger(trialNumber) || trialNumber <= 0) {
    throw new RangeError('trialNumber must be a positive integer');
  }

  return (1 - successProbability) ** (trialNumber - 1) * successProbability;
}
```

  if (!Number.isInteger(trialNumber) || trialNumber <= 0) {
    throw new RangeError('trialNumber must be a positive integer');
  }

  return (1 - successProbability) ** (trialNumber - 1) * successProbability;
}

## Follow-up Questions

- Add the cumulative probability of succeeding by or before trial `x`.
- Return the expected trial count `1 / p` and variance `(1 - p) / p^2`.
- Contrast this waiting-time model with the fixed-trial binomial distribution.

## Common Pitfalls

- Using `trialNumber` instead of `trialNumber - 1` in the failure exponent.
- Treating the prompt as a binomial count problem instead of a first-success problem.
- Forgetting that the trial number starts at `1`, not `0`.
