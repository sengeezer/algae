## Problem

Given a linked list and integers `M` and `N`, retain `M` nodes, delete the next `N` nodes, and repeat until the list ends.

## Approach

Use one pointer to move `M - 1` steps, then another loop to skip `N` nodes and reconnect.

**Time Complexity**: O(L)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function deleteNAfterM(head, m, n) {
  if (head === null || m <= 0) return null;

  let current = head;

  while (current !== null) {
    for (let i = 1; i < m && current !== null; i++) {
      current = current.next;
    }

    if (current === null) break;

    let toDelete = current.next;
    for (let i = 0; i < n && toDelete !== null; i++) {
      toDelete = toDelete.next;
    }

    current.next = toDelete;
    current = toDelete;
  }

  return head;
}
```
