## Problem

For each array element, find the first greater element to its right; if none, output `-1`.

## Approach

Scan from right to left with a decreasing stack. Remove elements that are not greater than current.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function nextGreaterElement(arr) {
  const n = arr.length;
  const result = new Array(n).fill(-1);
  const stack = [];

  for (let i = n - 1; i >= 0; i--) {
    while (stack.length > 0 && stack[stack.length - 1] <= arr[i]) {
      stack.pop();
    }

    result[i] = stack.length === 0 ? -1 : stack[stack.length - 1];
    stack.push(arr[i]);
  }

  return result;
}
```
