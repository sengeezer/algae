## Why It Surfaces

Möbius inversion shows up when a divisor-sum view is easy to compute but the interviewer really wants the original per-value function back. Instead of undoing that transform by ad hoc algebra for each `n`, the Möbius function supplies the exact inverse weights.

## Worked Example

Suppose the original function values are `f(1..6) = [1, 2, 3, 4, 5, 6]`, and define `g(n)` as the sum of `f(d)` over every divisor `d` of `n`. Then:

- `g(1) = 1`
- `g(2) = 1 + 2 = 3`
- `g(3) = 1 + 3 = 4`
- `g(4) = 1 + 2 + 4 = 7`
- `g(5) = 1 + 5 = 6`
- `g(6) = 1 + 2 + 3 + 6 = 12`

Möbius inversion takes `[1, 3, 4, 7, 6, 12]` and reconstructs the original `[1, 2, 3, 4, 5, 6]` exactly.

function computeMobiusValues(limit) {
  if (!Number.isInteger(limit) || limit < 1) {
    throw new RangeError('Limit must be a positive integer');
  }

  const mu = new Array(limit + 1).fill(0);
  const primes = [];
  const isComposite = new Array(limit + 1).fill(false);
  mu[1] = 1;

  for (let value = 2; value <= limit; value += 1) {
    if (!isComposite[value]) {
      primes.push(value);
      mu[value] = -1;
    }

    for (const prime of primes) {
      const composite = value * prime;
      if (composite > limit) {
        break;
      }

      isComposite[composite] = true;

      if (value % prime === 0) {
        mu[composite] = 0;
        break;
      }

      mu[composite] = -mu[value];
    }
  }

  return mu;
}

function divisorSumTransform(values) {
  validateSequence(values, 'values');

  const transformed = new Array(values.length).fill(0);

  for (let divisor = 1; divisor <= values.length; divisor += 1) {
    const contribution = values[divisor - 1];

    for (let multiple = divisor; multiple <= values.length; multiple += divisor) {
      transformed[multiple - 1] += contribution;
    }
  }

  return transformed;
}

function mobiusInvert(divisorSums) {
  validateSequence(divisorSums, 'divisorSums');

  const limit = divisorSums.length;
  const mu = computeMobiusValues(limit);
  const recovered = new Array(limit).fill(0);

  for (let divisor = 1; divisor <= limit; divisor += 1) {
    const weight = mu[divisor];
    if (weight === 0) {
      continue;
    }

    for (let multiple = divisor; multiple <= limit; multiple += divisor) {
      recovered[multiple - 1] += weight * divisorSums[multiple / divisor - 1];
    }
  }

  return recovered;
}

## Follow-up Questions

- Adapt the inversion helper to recover only one value `f(n)` instead of the entire prefix `f(1..n)`.
- Compare this full transform inversion with the simpler `Mobius Function` pointwise classifier.
- Combine Möbius inversion with a divisor-count or gcd-aggregate problem where the forward transform is easier than the original query.

## Common Pitfalls

- Mixing up `g(d)` and `g(n / d)` in the inversion formula.
- Treating Möbius inversion as a one-off prime-factorization trick instead of an inverse transform over divisors.
- Forgetting that the sieve must set `mu(k) = 0` as soon as any squared prime factor appears.
