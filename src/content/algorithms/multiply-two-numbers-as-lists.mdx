## Problem

Given two linked lists where each node contains one digit, multiply the two represented numbers and return the result under modulo `1e9 + 7`.

## Approach

Traverse each list and build its value as `value = (value * 10 + digit) % MOD`. Then return `(value1 * value2) % MOD`.

**Time Complexity**: O(n + m)
**Space Complexity**: O(1)

## Implementation

```javascript
const MOD = 1000000007n;

class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function listToNumberMod(head) {
  let value = 0n;
  let current = head;

  while (current !== null) {
    value = (value * 10n + BigInt(current.data)) % MOD;
    current = current.next;
  }

  return value;
}

function multiplyTwoNumbersAsLists(head1, head2) {
  const a = listToNumberMod(head1);
  const b = listToNumberMod(head2);
  return Number((a * b) % MOD);
}
```
