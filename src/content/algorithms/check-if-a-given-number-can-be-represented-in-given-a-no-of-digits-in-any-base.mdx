## Why It Surfaces

The problem asks if there exists a base `b` in `[2, 32]` such that `num` uses exactly `dig` digits in base `b`. For each base, repeatedly divide by `b` and count digits.

## Worked Example

- `num = 8, dig = 4` -> `Yes` (`1000` in base 2)
- `num = 8, dig = 2` -> `Yes` (`22` in base 3)
- `num = 8, dig = 3` -> `No`

```js
function canBeRepresentedInGivenDigitsAnyBase(num, dig) {
  if (!Number.isInteger(num) || num < 0) {
    throw new RangeError('Expected non-negative integer num');
  }
  if (!Number.isInteger(dig) || dig <= 0) {
    throw new RangeError('Expected positive integer dig');
  }

  const fitsBase = (n, digits, base) => {
    let value = n;
    let count = 1;

    while (value >= base && count < digits) {
      value = Math.floor(value / base);
      count += 1;
    }

    return count === digits && value < base;
  };

  for (let base = 2; base <= 32; base += 1) {
    if (fitsBase(num, dig, base)) {
      return true;
    }
    if (base > num && dig > 1) {
      break;
    }
  }

  return dig === 1 && num < 32;
}
```

## Common Pitfalls

- Treating leading zeros as allowed extra digits.
- Off-by-one mistakes in digit counting.
- Forgetting the base range limit 2..32.
