## Overview

This problem asks: "In how many ways can we choose non-negative integers a, b, c such that a + b + c = n?"

This is a classic combinatorics problem known as the **stars and bars** method. While a brute-force approach iterates through all triplets, the mathematical insight reveals a closed-form formula: `(n+1) * (n+2) / 2`.

The problem generalizes to: "distribute n identical objects into m distinct boxes" with solution formula: `C(n+m-1, m-1)` where C denotes the binomial coefficient.

## Examples

**n = 1:**
- (1, 0, 0), (0, 1, 0), (0, 0, 1) → **3 solutions**

**n = 2:**
- (2, 0, 0), (0, 2, 0), (0, 0, 2), (1, 1, 0), (1, 0, 1), (0, 1, 1) → **6 solutions**

**n = 3:**
- (3, 0, 0), (0, 3, 0), (0, 0, 3), (2, 1, 0), (2, 0, 1), (1, 2, 0), (1, 0, 2), (0, 2, 1), (1, 1, 1), (0, 1, 2) → **10 solutions**

## Brute Force Approach (O(n³))

```js
function countSolutionsBruteForce(n) {
  let count = 0;
  
  // Iterate through all possible values of a
  for (let a = 0; a <= n; a++) {
    // Iterate through all possible values of b
    for (let b = 0; b <= n - a; b++) {
      // Calculate c directly
      const c = n - a - b;
      if (c >= 0 && c <= n) {
        count++;
      }
    }
  }
  
  return count;
}

// Test cases
console.assert(countSolutionsBruteForce(1) === 3, "n=1 should have 3 solutions");
console.assert(countSolutionsBruteForce(2) === 6, "n=2 should have 6 solutions");
console.assert(countSolutionsBruteForce(3) === 10, "n=3 should have 10 solutions");
```

## Direct Formula (O(1))

The key insight: We need to distribute n identical items among 3 distinct boxes. This is equivalent to choosing 2 dividers from n + 2 positions (stars and bars).

**Formula:** `Count = (n+1) * (n+2) / 2`

This can be derived as: `C(n+3-1, 3-1) = C(n+2, 2) = (n+2)! / (2! * n!) = (n+1) * (n+2) / 2`

```js
function countSolutionsDirect(n) {
  // Formula: (n+1) * (n+2) / 2
  return ((n + 1) * (n + 2)) / 2;
}

// Test cases
console.assert(countSolutionsDirect(1) === 3, "n=1 should have 3 solutions");
console.assert(countSolutionsDirect(2) === 6, "n=2 should have 6 solutions");
console.assert(countSolutionsDirect(3) === 10, "n=3 should have 10 solutions");
console.assert(countSolutionsDirect(5) === 21, "n=5 should have 21 solutions");
console.assert(countSolutionsDirect(10) === 66, "n=10 should have 66 solutions");
```

## Generalization

For m variables: a₁ + a₂ + ... + aₘ = n (all non-negative)

**Formula:** `C(n+m-1, m-1)` where C is the binomial coefficient

For m = 3: `C(n+2, 2)`

For m = 4: `C(n+3, 3)`

## Dynamic Programming Variant

For constraints like a ≤ b ≤ c or when ranges are restricted, dynamic programming can count solutions:

```js
function countSolutionsDP(n) {
  // dp[i][j] = number of ways to get sum i using j variables
  const dp = Array(n + 1).fill(0).map(() => Array(4).fill(0));
  
  // Base case: sum 0 with any number of variables is 1 (all zeros)
  for (let j = 0; j <= 3; j++) {
    dp[0][j] = 1;
  }
  
  // Fill DP table
  for (let j = 1; j <= 3; j++) {
    for (let i = 1; i <= n; i++) {
      // Use 0, 1, 2, ... values of j-th variable
      for (let k = 0; k <= i; k++) {
        dp[i][j] += dp[i - k][j - 1];
      }
    }
  }
  
  return dp[n][3];
}

console.assert(countSolutionsDP(3) === 10, "DP: n=3 should have 10 solutions");
```
