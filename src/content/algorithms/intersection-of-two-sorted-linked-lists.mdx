## Problem

Given two sorted singly linked lists, return a new linked list containing only the values that appear in both lists, in sorted order.

## Approach

Traverse both lists together. If the current values match, append that value to the result and advance both pointers. Otherwise advance the pointer with the smaller value.

**Time Complexity**: O(m + n)
**Space Complexity**: O(k)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function intersectionOfTwoSortedLinkedLists(head1, head2) {
  const dummy = new Node(0);
  let tail = dummy;

  let left = head1;
  let right = head2;

  while (left !== null && right !== null) {
    if (left.data === right.data) {
      tail.next = new Node(left.data);
      tail = tail.next;
      left = left.next;
      right = right.next;
    } else if (left.data < right.data) {
      left = left.next;
    } else {
      right = right.next;
    }
  }

  return dummy.next;
}
```
