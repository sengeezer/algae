## Why It Surfaces

This prompt looks like expression parsing, but the catch is that precedence is intentionally removed. `1 + 2 * 3` is treated as `(1 + 2) * 3`, not `1 + (2 * 3)`, so the real task is to validate the token stream and fold it strictly from left to right.

## Worked Example

- `1 + 2 * 3` evaluates to `9`
- `4 - 2 + 6 * 3` evaluates to `24`
- `1++2` is invalid, so the function returns `-1`

function applyOperator(left, operator, right) {
  switch (operator) {
    case '+':
      return left + right;
    case '-':
      return left - right;
    case '*':
      return left * right;
    default:
      return null;
  }
}

function evaluateSimpleExpression(expression) {
  if (typeof expression !== 'string') {
    return -1;
  }

  let index = 0;

  function skipSpaces() {
    while (index < expression.length && expression[index] === ' ') {
      index += 1;
    }
  }

  function readNumber() {
    skipSpaces();

    const start = index;
    while (index < expression.length && expression[index] >= '0' && expression[index] <= '9') {
      index += 1;
    }

    if (start === index) {
      return null;
    }

    return Number(expression.slice(start, index));
  }

  let total = readNumber();
  if (total === null) {
    return -1;
  }

  while (true) {
    skipSpaces();

    if (index === expression.length) {
      return total;
    }

    const operator = expression[index];
    index += 1;

    const nextValue = readNumber();
    if (nextValue === null) {
      return -1;
    }

    const updated = applyOperator(total, operator, nextValue);
    if (updated === null) {
      return -1;
    }

    total = updated;
  }
}

## Follow-up Questions

- Extend the evaluator to support `/` while still validating syntax.
- Add true precedence and parentheses support with stacks or recursive descent parsing.
- Return a structured error instead of the sentinel value `-1`.

## Common Pitfalls

- Accidentally applying normal precedence rules when the prompt explicitly forbids them.
- Accepting malformed input like `1++2` or a trailing operator.
- Forgetting to ignore spaces that appear between tokens.
