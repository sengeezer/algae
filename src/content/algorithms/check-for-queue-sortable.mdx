## Problem

Given a permutation of `1..n`, check whether it is queue-sortable using one auxiliary stack.

## Approach

Simulate reading values in order and producing sorted output while temporarily storing obstructing values in stack.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function isQueueSortable(arr) {
  const stack = [];
  let need = 1;

  for (const x of arr) {
    while (stack.length > 0 && stack[stack.length - 1] === need) {
      stack.pop();
      need++;
    }

    if (x === need) {
      need++;
    } else {
      stack.push(x);
    }
  }

  while (stack.length > 0 && stack[stack.length - 1] === need) {
    stack.pop();
    need++;
  }

  return need === arr.length + 1;
}
```
