## Problem

Given a sequence of words, repeatedly delete adjacent equal words until no such pair remains.

## Approach

Traverse words and use a stack: if the top equals the current word, pop it; otherwise push the current word.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function deleteConsecutiveSameWords(words) {
  const stack = [];

  for (const word of words) {
    if (stack.length > 0 && stack[stack.length - 1] === word) {
      stack.pop();
    } else {
      stack.push(word);
    }
  }

  return stack;
}
```
