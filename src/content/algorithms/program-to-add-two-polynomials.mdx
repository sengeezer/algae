## Why It Surfaces

When polynomials are encoded as arrays where index = exponent, addition is direct:

- `sum[i] = A[i] + B[i]` for all valid indices
- missing terms are treated as `0`

## Worked Example

- `A = [5, 0, 10, 6]`
- `B = [1, 2, 4]`
- `sum = [6, 2, 14, 6]`

## Reference Implementations

<ExamplePair>

```js
function programToAddTwoPolynomials(A, B) {
  if (!Array.isArray(A) || !Array.isArray(B)) {
    throw new TypeError('Expected two coefficient arrays');
  }

  const size = Math.max(A.length, B.length);
  const sum = new Array(size).fill(0);

  for (let i = 0; i < size; i += 1) {
    const a = i < A.length ? A[i] : 0;
    const b = i < B.length ? B[i] : 0;
    sum[i] = a + b;
  }

  return sum;
}
```
