## Why It Surfaces

This is a classic long-division simulation. If `rem` is current remainder, then each next digit after decimal is:

- `digit = floor((10 * rem) / n)`
- `rem = (10 * rem) % n`

Start with `rem = 1` for `1/n`.

## Worked Example

- `n = 3`, `k = 3` gives `333`
- `n = 50`, `k = 4` gives `0200`

## Reference Implementations

<ExamplePair>

```js
function printFirstKDigitsOf1ByN(n, k) {
  if (!Number.isInteger(n) || n <= 0) {
    throw new RangeError('Expected positive integer n');
  }
  if (!Number.isInteger(k) || k < 0) {
    throw new RangeError('Expected non-negative integer k');
  }

  let rem = 1 % n;
  let digits = '';

  for (let i = 0; i < k; i += 1) {
    const value = rem * 10;
    digits += Math.floor(value / n).toString();
    rem = value % n;
  }

  return digits;
}
```
