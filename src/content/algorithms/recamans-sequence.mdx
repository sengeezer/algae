## Why It Surfaces

Recaman's sequence is a clean simulation problem with a subtle constraint: candidate values must be positive and unseen. This turns a simple recurrence into a stateful process where a visited set is the key optimization.

## Worked Example

- For `n = 6`, terms are: `0, 1, 3, 6, 2, 7`
- For `n = 17`, terms are: `0, 1, 3, 6, 2, 7, 13, 20, 12, 21, 11, 22, 10, 23, 9, 24, 8`

## Reference Implementations

<ExamplePair>

```js
function recamansSequence(n) {
  if (!Number.isInteger(n) || n <= 0) {
    throw new RangeError('Expected a positive integer n');
  }

  const sequence = new Array(n).fill(0);
  const seen = new Set([0]);

  for (let i = 1; i < n; i += 1) {
    let candidate = sequence[i - 1] - i;
    if (candidate < 0 || seen.has(candidate)) {
      candidate = sequence[i - 1] + i;
    }
    sequence[i] = candidate;
    seen.add(candidate);
  }

  return sequence;
}
```

  const sequence: number[] = new Array(n).fill(0);
  const seen = new Set<number>([0]);

    }
    sequence[i] = candidate;
    seen.add(candidate);
  }

  return sequence;
}
