## Why It Surfaces

Padovan is a standard recurrence interview prompt because it looks Fibonacci-like but shifts dependencies. The key transition is:

`P(n) = P(n - 2) + P(n - 3)`, with `P(0)=P(1)=P(2)=1`.

## Worked Example

- Sequence prefix: `1, 1, 1, 2, 2, 3, 4, 5, 7, 9, 12, 16, 21, ...`
- `P(12) = 21`

## Reference Implementations

<ExamplePair>

```js
function padovanSequence(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError('Expected a non-negative integer index');
  }

  if (n <= 2) {
    return 1;
  }

  let pNm3 = 1;
  let pNm2 = 1;
  let pNm1 = 1;

  for (let i = 3; i <= n; i += 1) {
    const current = pNm3 + pNm2;
    pNm3 = pNm2;
    pNm2 = pNm1;
    pNm1 = current;
  }

  return pNm1;
}
```
