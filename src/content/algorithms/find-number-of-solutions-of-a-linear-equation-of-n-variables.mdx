## Why It Surfaces

For equation

`coeff[0] * x0 + coeff[1] * x1 + ... + coeff[n-1] * x(n-1) = rhs`

with `xi >= 0`, this is equivalent to counting ways to make sum `rhs` using unlimited copies of each coefficient.

DP recurrence:

- `dp[0] = 1`
- for each coefficient `c`:
  - for `s` from `c` to `rhs`: `dp[s] += dp[s - c]`

## Worked Example

- `coeff = [1, 2], rhs = 5` -> `3`
- `coeff = [2, 2, 3], rhs = 4` -> `3`

## Reference Implementations

<ExamplePair>

```js
function findNumberOfSolutionsOfALinearEquationOfNVariables(coeff, rhs) {
  if (!Array.isArray(coeff) || coeff.length === 0 || !Number.isInteger(rhs) || rhs < 0) {
    throw new RangeError('Expected non-empty coefficient array and non-negative rhs');
  }
  if (coeff.some((c) => !Number.isInteger(c) || c <= 0)) {
    throw new RangeError('All coefficients must be positive integers');
  }

  const dp = new Array(rhs + 1).fill(0);
  dp[0] = 1;

  for (const c of coeff) {
    for (let s = c; s <= rhs; s += 1) {
      dp[s] += dp[s - c];
    }
  }

  return dp[rhs];
}
```

## Common Pitfalls

- Looping rhs before coefficients and accidentally counting permutations.
- Allowing zero or negative coefficients.
- Missing base case `dp[0] = 1`.
