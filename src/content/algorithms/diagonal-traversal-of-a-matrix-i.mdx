## Why It Surfaces

This problem checks whether you can move across a matrix in a less familiar order than rows, columns, or spirals. The key observation is that every bottom-left to top-right diagonal can be identified by its starting point, and those starts come from the first column followed by the bottom row.

## Worked Example

For `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]`, the traversal starts at `[0, 0]` and yields `1`, then at `[1, 0]` and yields `4, 2`, then `[2, 0]` for `7, 5, 3`, and finally the remaining bottom-row starts `[2, 1]` and `[2, 2]` for `8, 6` and `9`. The full diagonal order is `[1, 4, 2, 7, 5, 3, 8, 6, 9]`.

function validateNumericMatrix(matrix) {
  if (!Array.isArray(matrix) || matrix.length === 0 || !matrix.every((row) => Array.isArray(row))) {
    throw new TypeError('matrix must be a non-empty 2D array');
  }

  const width = matrix[0].length;
  if (width === 0) {
    throw new TypeError('matrix rows must not be empty');
  }

  if (!matrix.every((row) => row.length === width && row.every((value) => Number.isFinite(value)))) {
    throw new TypeError('matrix rows must have equal length and contain only finite numbers');
  }
}

function diagonalTraversalOfAMatrixI(matrix) {
  validateNumericMatrix(matrix);

  const rows = matrix.length;
  const cols = matrix[0].length;
  const result = [];

  for (let startRow = 0; startRow < rows; startRow += 1) {
    let row = startRow;
    let col = 0;

    while (row >= 0 && col < cols) {
      result.push(matrix[row][col]);
      row -= 1;
      col += 1;
    }
  }

  for (let startCol = 1; startCol < cols; startCol += 1) {
    let row = rows - 1;
    let col = startCol;

    while (row >= 0 && col < cols) {
      result.push(matrix[row][col]);
      row -= 1;
      col += 1;
    }
  }

  return result;
}

## Follow-up Questions

- How would you alternate diagonal direction to produce a true zigzag traversal?
- What changes if you want top-left to bottom-right anti-diagonals instead?
- How would you return one array per diagonal instead of one flattened traversal?

## Common Pitfalls

- Starting the second phase from the first bottom-row column and duplicating the bottom-left diagonal.
- Moving down-right instead of up-right within each diagonal.
- Assuming the matrix is square when the traversal works for rectangular inputs too.
