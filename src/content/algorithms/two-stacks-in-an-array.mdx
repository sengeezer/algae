## Problem

Design a data structure that supports two stacks in a single array with `push1`, `push2`, `pop1`, and `pop2`.

## Approach

Use `top1` starting at `-1` and `top2` starting at `capacity`. Pushes move inward; pops move outward.

**Time Complexity**: O(1) per operation
**Space Complexity**: O(capacity)

## Implementation

```javascript
class TwoStacks {
  constructor(capacity) {
    this.arr = new Array(capacity);
    this.top1 = -1;
    this.top2 = capacity;
  }

  push1(value) {
    if (this.top1 + 1 === this.top2) throw new Error('Overflow');
    this.arr[++this.top1] = value;
  }

  push2(value) {
    if (this.top1 + 1 === this.top2) throw new Error('Overflow');
    this.arr[--this.top2] = value;
  }

  pop1() {
    if (this.top1 < 0) throw new Error('Underflow');
    return this.arr[this.top1--];
  }

  pop2() {
    if (this.top2 >= this.arr.length) throw new Error('Underflow');
    return this.arr[this.top2++];
  }
}
```
