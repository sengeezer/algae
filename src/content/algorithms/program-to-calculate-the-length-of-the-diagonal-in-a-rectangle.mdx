## Why It Surfaces

This is the rectangle version of the Pythagorean theorem. Once you notice that the diagonal splits the rectangle into two right triangles, the whole problem becomes the same as finding the hypotenuse from two legs.

## Worked Example

For `length = 8` and `width = 6`, the diagonal is `sqrt(8^2 + 6^2) = sqrt(100) = 10`.

## Reference Implementations

<ExamplePair>

```js
function programToCalculateTheLengthOfTheDiagonalInARectangle(length, width) {
  if (
    typeof length !== 'number' ||
    typeof width !== 'number' ||
    !Number.isFinite(length) ||
    !Number.isFinite(width) ||
    length <= 0 ||
    width <= 0
  ) {
    throw new RangeError('Rectangle side lengths must be positive finite numbers');
  }

  return Math.hypot(length, width);
}

function approximatelyEqual(left, right, epsilon = 1e-12) {
  return Math.abs(left - right) <= epsilon;
}

console.assert(
  approximatelyEqual(programToCalculateTheLengthOfTheDiagonalInARectangle(8, 6), 10),
  '8 by 6 rectangle should have diagonal 10'
);
console.assert(
  approximatelyEqual(programToCalculateTheLengthOfTheDiagonalInARectangle(5, 12), 13),
  '5 by 12 rectangle should have diagonal 13'
);
```

## Common Pitfalls

- Mixing diagonal length up with perimeter.
- Accepting zero or negative side lengths as valid input.
- Squaring the sum `length + width` instead of summing the squares of each side.
