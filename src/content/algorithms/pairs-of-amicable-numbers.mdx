## Why It Surfaces

Amicable number prompts typically ask: given a collection, find or count the pairs (a, b) where each number's proper-divisor sum equals the other. This is distinct from enumeration problems that list all amicable pairs below a limit, focusing instead on membership testing and pair extraction within a fixed dataset.

## Worked Example

In the array `[220, 284, 50, 100]`, the pair `(220, 284)` is amicable because the proper divisors of `220` (1, 2, 4, 5, 10, 11, 20, 22, 44, 55, 110) sum to `284`, and the proper divisors of `284` (1, 2, 4, 71, 142) sum to `220`. The other elements are not part of amicable pairs.

function sumProperDivisors(value) {
  if (value <= 1) {
    return 0;
  }

  let sum = 1;

  for (let divisor = 2; divisor * divisor <= value; divisor += 1) {
    if (value % divisor !== 0) {
      continue;
    }

    sum += divisor;
    const pairedDivisor = value / divisor;

    if (pairedDivisor !== divisor) {
      sum += pairedDivisor;
    }
  }

  return sum;
}

function findAmicablePairs(numbers) {
  if (!Array.isArray(numbers)) {
    throw new TypeError('Input must be an array');
  }

  const divisorSumMap = new Map();

  for (const num of numbers) {
    if (!Number.isInteger(num) || num < 1) {
      continue;
    }

    divisorSumMap.set(num, sumProperDivisors(num));
  }

  const pairs = [];

  for (const [num, divisorSum] of divisorSumMap) {
    if (
      divisorSum !== num &&
      divisorSumMap.has(divisorSum) &&
      divisorSumMap.get(divisorSum) === num
    ) {
      pairs.push([Math.min(num, divisorSum), Math.max(num, divisorSum)]);
    }
  }

  // Remove duplicate pairs (e.g., [220, 284] and [284, 220] are the same)
  const uniquePairs = [];
  const seen = new Set();

  for (const [a, b] of pairs) {
    const key = `${a},${b}`;
    if (!seen.has(key)) {
      uniquePairs.push([a, b]);
      seen.add(key);
    }
  }

  return uniquePairs;
}

console.assert(
  JSON.stringify(findAmicablePairs([220, 284])) === JSON.stringify([[220, 284]]),
  'Found amicable pair (220, 284)'
);
console.assert(
  findAmicablePairs([100, 200, 300]).length === 0,
  'No amicable pairs in [100, 200, 300]'
);
console.assert(
  findAmicablePairs([220, 284, 1184, 1210]).length === 2,
  'Found two amicable pairs'
);

## Key Insights

- **Proper divisors** of a number include all divisors except the number itself.
- **Amicable pairs** form a bidirectional relationship: if $s(a) = b$ then $s(b) = a$ (where $s(n)$ is the sum of proper divisors).
- The smallest amicable pair is **(220, 284)**, known since ancient times.
- Finding pairs in a fixed collection is O(n) after the divisor-sum precomputation, making this more efficient than range-based enumeration.
