## Why It Surfaces

For polynomials A and B, each coefficient pair contributes to degree `i + j`.

- If `A[i]` multiplies `B[j]`, add product to `prod[i + j]`.
- Output size is always `A.length + B.length - 1`.

## Worked Example

- `A = [5, 0, 10, 6]`
- `B = [1, 2, 4]`
- `prod = [5, 10, 30, 26, 52, 24]`

## Reference Implementations

<ExamplePair>

```js
function multiplyTwoPolynomials(A, B) {
  if (!Array.isArray(A) || !Array.isArray(B)) {
    throw new TypeError('Expected two coefficient arrays');
  }
  if (A.length === 0 || B.length === 0) {
    return [];
  }

  const prod = new Array(A.length + B.length - 1).fill(0);

  for (let i = 0; i < A.length; i += 1) {
    for (let j = 0; j < B.length; j += 1) {
      prod[i + j] += A[i] * B[j];
    }
  }

  return prod;
}
```
