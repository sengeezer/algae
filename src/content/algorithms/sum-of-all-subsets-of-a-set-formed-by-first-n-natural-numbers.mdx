## Why It Surfaces

This is the cleanest contribution-counting version of subset enumeration. Instead of generating every subset, count how many times each number from `1` to `n` appears: once you decide whether a value is in or out, the remaining `n - 1` values can vary freely, so each value appears in exactly `2^(n - 1)` non-empty subsets.

## Worked Example

For `n = 3`, the non-empty subsets are `{1}`, `{2}`, `{3}`, `{1, 2}`, `{1, 3}`, `{2, 3}`, and `{1, 2, 3}`. Summing their elements gives `24`. The shortcut reaches the same answer with `((3 * 4) / 2) * 2^(3 - 1) = 6 * 4 = 24`.

```js
function sumOfAllSubsetsOfASetFormedByFirstNNaturalNumbers(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError('n must be a non-negative integer');
  }

  if (n === 0) {
    return 0;
  }

  const arithmeticSeriesTotal = (n * (n + 1)) / 2;
  return arithmeticSeriesTotal * 2 ** (n - 1);
}
```

## Follow-up Questions

- Generalize the same contribution argument to an arbitrary array instead of `1..n`.
- Return the answer modulo a large prime when `n` is large.
- Explain why every value appears in exactly half of the subsets.

## Common Pitfalls

- Generating the entire power set even though the prompt only asks for the aggregate total.
- Forgetting that the empty subset contributes `0`, so it does not change the result.
- Mixing up the arithmetic-series total `n * (n + 1) / 2` with the subset multiplier `2^(n - 1)`.
