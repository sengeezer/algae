## Why It Surfaces

Poisson distribution is the interview-friendly model for exact event counts when the prompt gives an average rate rather than a fixed number of trials. The key implementation detail is to compute the PMF without separately expanding a large factorial.

## Worked Example

Suppose a help desk receives `lambda = 4` urgent tickets per hour on average. The probability of receiving exactly `k = 2` tickets in the next hour is:

`P(X = 2) = e^-4 * 4^2 / 2! = e^-4 * 8 ≈ 0.1465`

## Reference Implementations

<ExamplePair>

```js
function poissonDistribution(lambda, observedEvents) {
  if (typeof lambda !== 'number' || !Number.isFinite(lambda) || lambda < 0) {
    throw new RangeError('lambda must be a non-negative finite number');
  }

  if (!Number.isInteger(observedEvents) || observedEvents < 0) {
    throw new RangeError('observedEvents must be a non-negative integer');
  }

  let probability = Math.exp(-lambda);

  for (let step = 1; step <= observedEvents; step += 1) {
    probability = (probability * lambda) / step;
  }

  return probability;
}
```

## Follow-up Questions

- Extend the helper to return `P(X <= k)` by summing the PMF up to `k`.
- Use the recurrence `P(k) = lambda / k * P(k - 1)` to generate a full table of probabilities.
- Compare when Poisson is a good approximation to binomial distribution.

## Common Pitfalls

- Forgetting that `k` must be a non-negative integer.
- Computing `lambda^k` and `k!` separately and losing precision earlier than necessary.
- Confusing the average rate `lambda` with a fixed number of Bernoulli trials.
