## Why It Surfaces

Variance and standard deviation are the first statistics helpers where a straightforward formula still needs careful implementation details. The main fork in the road is whether the prompt wants population statistics or sample statistics with Bessel's correction.

## Worked Example

For `[2, 4, 6, 8]`, the mean is `5`.

- squared deviations: `[9, 1, 1, 9]`
- population variance: `(9 + 1 + 1 + 9) / 4 = 5`
- population standard deviation: `sqrt(5) ≈ 2.2361`

## Reference Implementations

<ExamplePair>

```js
function varianceAndStandardDeviation(values, sample = false) {
  if (!Array.isArray(values) || values.length === 0) {
    throw new RangeError('Expected a non-empty array of numbers');
  }

  if (sample && values.length < 2) {
    throw new RangeError('Sample statistics require at least two values');
  }

  let total = 0;

  for (const value of values) {
    if (typeof value !== 'number' || !Number.isFinite(value)) {
      throw new TypeError('All values must be finite numbers');
    }

    total += value;
  }

  const mean = total / values.length;
  let squaredDeviationSum = 0;

  for (const value of values) {
    const difference = value - mean;
    squaredDeviationSum += difference * difference;
  }

  const divisor = sample ? values.length - 1 : values.length;
  const variance = squaredDeviationSum / divisor;

  return {
    mean,
    variance,
    standardDeviation: Math.sqrt(variance),
  };
}
```

## Common Pitfalls

- Using `n` when the prompt actually wants sample variance with `n - 1`.
- Forgetting to compute the mean before accumulating squared deviations.
- Treating variance and standard deviation as interchangeable even though their units differ.
