## Problem

Given heads of two singly linked lists, return the node where they intersect by reference, or `null` if they do not intersect.

## Approach

Use pointers `a` and `b` starting at each head. Advance both by one. When one reaches null, redirect it to the other head. They meet at intersection or both become null.

**Time Complexity**: O(m + n)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function intersectionPointOfTwoLinkedLists(headA, headB) {
  let a = headA;
  let b = headB;

  while (a !== b) {
    a = a === null ? headB : a.next;
    b = b === null ? headA : b.next;
  }

  return a;
}
```

function intersectionPointOfTwoLinkedLists(headA: Node | null, headB: Node | null): Node | null {
  let a: Node | null = headA;
  let b: Node | null = headB;

  while (a !== b) {
    a = a === null ? headB : a.next;
    b = b === null ? headA : b.next;
  }

  return a;
}
