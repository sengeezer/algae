## Problem

Given a binary tree, flatten it in-place to a linked list. The flattened tree should have the same structure as a pre-order traversal of the tree, where each node's left pointer is null and right pointer points to the next node.

### Examples

**Example 1:**
```
Input:     
       1
      / \
     2   5
    / \   \
   3   4   6

Flattened:
1 -> 2 -> 3 -> 4 -> 5 -> 6
(All left pointers null, right pointer follows pre-order)
```

**Example 2:**
```
Input:     
       1
        \
         2
        /
       3

Flattened:
1 -> 2 -> 3
```

## Approach

### Recursive Approach
1. Recursively flatten left and right subtrees
2. Connect current node's right to flattened left subtree
3. Find the tail of left subtree and connect to right subtree
4. Update current node's left to null

### Iterative Approach
Use pre-order traversal with stack to flatten.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Flatten binary tree to linked list
 * Time: O(n), Space: O(h)
 */
function flatten(root) {
  function flattenHelper(node) {
    if (node === null) return null;

    // Recursively flatten left and right subtrees
    const leftTail = flattenHelper(node.left);
    const rightTail = flattenHelper(node.right);

    // If left subtree exists, connect it to right
    if (leftTail !== null) {
      leftTail.right = node.right;
      node.right = node.left;
      node.left = null;
    }

    // Return the tail of the flattened tree
    return rightTail !== null ? rightTail : leftTail !== null ? leftTail : node;
  }

  flattenHelper(root);
  return root;
}

/**
 * Flatten using pre-order traversal with previous tracking
 * Time: O(n), Space: O(h)
 */
function flattenPreorder(root) {
  let prev = null;

  function preorder(node) {
    if (node === null) return;

    const left = node.left;
    const right = node.right;

    // Process current node
    if (prev !== null) {
      prev.right = node;
    }
    node.left = null;
    prev = node;

    // Pre-order: root, left, right
    preorder(left);
    preorder(right);
  }

  preorder(root);
  return root;
}

/**
 * Iterative approach using stack
 * Time: O(n), Space: O(h)
 */
function flattenIterative(root) {
  if (root === null) return root;

  const stack = [root];

  while (stack.length > 0) {
    const node = stack.pop();

    // Push right before left so left is processed first
    if (node.right !== null) {
      stack.push(node.right);
    }
    if (node.left !== null) {
      stack.push(node.left);
    }

    // Connect to next node
    if (stack.length > 0) {
      node.right = stack[stack.length - 1];
    }
    node.left = null;
  }

  return root;
}

/**
 * Print flattened structure
 */
function printFlattened(root) {
  const result = [];
  let current = root;
  while (current !== null) {
    result.push(current.val);
    current = current.right;
  }
  return result;
}
```

## Key Properties

- **Pre-order Sequence:** Flattened structure follows pre-order (root, left, right)
- **Left Null:** All left pointers become null
- **In-place:** Can modify tree structure without creating new nodes
- **Linked List Form:** Traversing right pointers gives pre-order

## Complexity Analysis

- **Time:** O(n) - visit each node once
- **Space (Recursive):** O(h) - recursion depth
- **Space (Iterative):** O(h) - stack size
