## Problem

Given a singly linked list and a pivot value `x`, rearrange the list so nodes with values smaller than `x` come before nodes with values greater than or equal to `x`, while preserving original relative order inside each group.

## Approach

Maintain two temporary lists: one for nodes `< x` and one for nodes `>= x`. Traverse once, append each node to the correct tail, then join the two lists.

**Time Complexity**: O(n)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function partitionList(head, pivot) {
  const smallerDummy = new Node(0);
  const greaterDummy = new Node(0);

  let smallerTail = smallerDummy;
  let greaterTail = greaterDummy;
  let current = head;

  while (current !== null) {
    const next = current.next;
    current.next = null;

    if (current.data < pivot) {
      smallerTail.next = current;
      smallerTail = current;
    } else {
      greaterTail.next = current;
      greaterTail = current;
    }

    current = next;
  }

  smallerTail.next = greaterDummy.next;
  return smallerDummy.next;
}
```
