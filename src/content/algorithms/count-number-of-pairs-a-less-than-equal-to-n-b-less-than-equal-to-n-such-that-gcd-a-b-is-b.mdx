## Why It Surfaces

This looks like a pairwise gcd problem, but the real reduction is arithmetic. Once you notice that `gcd(a, b) = b` means `b` divides `a`, the answer becomes the number of multiples of each `b` up to `n`.

## Worked Example

- For `n = 2`, valid ordered pairs are `(1, 1)`, `(2, 1)`, and `(2, 2)`, so the answer is `3`.
- For `n = 3`, the count is `floor(3 / 1) + floor(3 / 2) + floor(3 / 3) = 3 + 1 + 1 = 5`.

```js
function countNumberOfPairsALessThanEqualToNBLessThanEqualToNSuchThatGcdABIsB(n) {
  if (!Number.isInteger(n) || n < 1) {
    throw new RangeError("Expected a positive integer");
  }

  let total = 0;
  let start = 1;

  while (start <= n) {
    const quotient = Math.floor(n / start);
    const end = Math.floor(n / quotient);
    total += quotient * (end - start + 1);
    start = end + 1;
  }

  return total;
}
```

## Common Pitfalls

- Treating the condition as if both values had to divide each other.
- Enumerating all `n^2` pairs instead of reducing to divisibility counts.
- Forgetting that the pairs are ordered, so `(a, b)` and `(b, a)` are different prompts unless stated otherwise.
