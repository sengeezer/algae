## Why It Surfaces

We need count of `x` where `x - digitSum(x) > s` for `1 <= x <= n`.

Observations:

- For very large numbers, `digitSum(x)` is at most bounded by number-of-digits times 9.
- So once condition is true at some `x0`, it stays true for all sufficiently larger `x`.

For typical 64-bit sized inputs, checking from `s` to `min(n, s + 163)` is enough to find first valid `x`.

## Worked Example

- `n = 20, s = 5` -> `11`
- `n = 20, s = 20` -> `0`

## Reference Implementations

<ExamplePair>

```js
function numbersHavingDifferenceWithDigitSumMoreThanS(n, s) {
  if (!Number.isInteger(n) || !Number.isInteger(s) || n < 0 || s < 0) {
    throw new RangeError('Expected non-negative integers n and s');
  }
  if (n <= s) {
    return 0;
  }

  const digitSum = (x) => {
    let sum = 0;
    let value = x;
    while (value > 0) {
      sum += value % 10;
      value = Math.floor(value / 10);
    }
    return sum;
  };

  const upper = Math.min(n, s + 163);
  for (let x = Math.max(1, s); x <= upper; x += 1) {
    if (x - digitSum(x) > s) {
      return n - x + 1;
    }
  }

  return 0;
}
```

## Common Pitfalls

- Scanning from `1` to `n` unnecessarily.
- Forgetting the fast return when `n <= s`.
- Off-by-one in suffix count `n - x + 1`.
