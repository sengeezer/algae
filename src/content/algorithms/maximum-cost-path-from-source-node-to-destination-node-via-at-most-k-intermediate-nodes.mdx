## Problem

Given a weighted directed graph, a source, a destination, and a limit on intermediate nodes, return the maximum path cost that respects the limit.

## Approach

Build an adjacency list and run BFS-like layered expansion from the source. Each queue entry carries the current node and accumulated cost, and each layer increases the number of intermediates by one.

**Time Complexity**: O(V + E)
**Space Complexity**: O(V + E)

## Implementation

```javascript
function maximumCostPath(graph, source, destination, maxIntermediates) {
  const queue = [[source, 0]];
  let head = 0;
  let level = 0;
  let best = Number.NEGATIVE_INFINITY;

  while (head < queue.length && level <= maxIntermediates + 1) {
    const levelSize = queue.length - head;

    for (let i = 0; i < levelSize; i++) {
      const [node, cost] = queue[head++];

      if (node === destination) {
        best = Math.max(best, cost);
      }

      for (const [nextNode, weight] of graph[node] ?? []) {
        queue.push([nextNode, cost + weight]);
      }
    }

    level += 1;
  }

  return best === Number.NEGATIVE_INFINITY ? -1 : best;
}
```
