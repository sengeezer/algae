## Problem

Given a binary tree, convert it to a binary search tree while maintaining its structure as much as possible. One approach is to collect all values via in-order traversal, sort them, and reconstruct as a balanced BST.

### Examples

**Example 1:**
```
Input: 
      2
     / \
    1   3

After sorting and reconstruction:
      2
     / \
    1   3
(Already a BST)
```

**Example 2:**
```
Input: 
      5
     / \
    3   7
   / 
  2   

Values: [5, 3, 7, 2] => sorted: [2, 3, 5, 7]

Output:
      5
     / \
    3   7
   / 
  2   
```

## Approach

### Method 1: In-order Traversal + Reconstruction
1. Collect all values using in-order traversal
2. Sort the values
3. Reconstruct BST from sorted values using in-order assignment

### Method 2: Direct Transformation
Perform in-order traversal and assign values from sorted array on-the-fly.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Convert binary tree to BST
 * Time: O(n log n), Space: O(n)
 */
function binaryTreeToBST(root) {
  if (root === null) return null;

  // Step 1: Collect all values via in-order traversal
  const values = [];
  function inorder(node) {
    if (node === null) return;
    inorder(node.left);
    values.push(node.val);
    inorder(node.right);
  }
  inorder(root);

  // Step 2: Sort values
  values.sort((a, b) => a - b);

  // Step 3: Reconstruct tree with sorted values via in-order assignment
  let index = 0;
  function assignValues(node) {
    if (node === null) return;
    assignValues(node.left);
    node.val = values[index++];
    assignValues(node.right);
  }
  assignValues(root);

  return root;
}

/**
 * Build balanced BST from sorted array
 * Time: O(n), Space: O(log n)
 */
function buildBSTFromArray(values) {
  function buildBST(start, end) {
    if (start > end) return null;

    const mid = Math.floor((start + end) / 2);
    const node = new TreeNode(values[mid]);

    node.left = buildBST(start, mid - 1);
    node.right = buildBST(mid + 1, end);

    return node;
  }

  return buildBST(0, values.length - 1);
}

/**
 * Two-step conversion: extract then build
 * Time: O(n log n), Space: O(n)
 */
function convertBinaryTreeToBST(root) {
  const values = [];

  // In-order traversal to collect values
  function inorder(node) {
    if (node === null) return;
    inorder(node.left);
    values.push(node.val);
    inorder(node.right);
  }

  inorder(root);
  values.sort((a, b) => a - b);

  // Build balanced BST from sorted values
  return buildBSTFromArray(values);
}
```

## Key Properties

- **In-order Traversal:** Extracts values in binary tree order
- **Sorting:** Essential for BST construction
- **Reconstruction:** Uses mid-point selection for balance

## Complexity Analysis

- **Time:** O(n log n) - dominated by sorting
- **Space:** O(n) - for storing all values
