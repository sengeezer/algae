## Why It Surfaces

The naive solution builds every pair from the two arrays and searches for the best one. The key observation is that the maximum weighted pair must use the maximum value from the left array and the maximum value from the right array, so only the frequencies of those two maxima matter.

## Worked Example

Let `A = [1, 2, 3]` and `B = [1, 3, 3]`.

- The maximum in `A` is `3`, and it appears `1` time.
- The maximum in `B` is `3`, and it appears `2` times.
- Total pairs: `3 * 3 = 9`
- Favorable pairs: `1 * 2 = 2`

So the probability is `2 / 9 ≈ 0.2222`.

function countMaximumOccurrences(values) {
  let maximum = -Infinity;
  let count = 0;

  for (const value of values) {
    if (typeof value !== 'number' || !Number.isFinite(value)) {
      throw new TypeError('All array elements must be finite numbers');
    }

    if (value > maximum) {
      maximum = value;
      count = 1;
    } else if (value === maximum) {
      count += 1;
    }
  }

  return count;
}

function probabilityOfARandomPairBeingTheMaximumWeightedPair(leftValues, rightValues) {
  if (!Array.isArray(leftValues) || !Array.isArray(rightValues)) {
    throw new TypeError('Expected two arrays of numbers');
  }

  if (leftValues.length === 0 || rightValues.length === 0) {
    throw new RangeError('Both arrays must be non-empty');
  }

  const leftMaximumCount = countMaximumOccurrences(leftValues);
  const rightMaximumCount = countMaximumOccurrences(rightValues);
  const totalPairs = leftValues.length * rightValues.length;
  const favorablePairs = leftMaximumCount * rightMaximumCount;

  return favorablePairs / totalPairs;
}

## Follow-up Questions

- Return the exact reduced fraction instead of a floating-point probability.

## Common Pitfalls

- Enumerating all pairs even though only the maximum frequencies matter.
- Forgetting that repeated maximum values create multiple favorable pairs.
- Skipping validation for empty arrays.
