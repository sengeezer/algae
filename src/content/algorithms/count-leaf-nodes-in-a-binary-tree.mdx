## Problem

Given the root of a binary tree, count the total number of leaf nodes. A leaf node is a node with no children (both left and right are null).

### Examples

**Example 1:**
```
Input:     
      1
     / \
    2   3

Output: 2 (nodes 2 and 3 are leaves)
```

**Example 2:**
```
Input:     
        1
       / \
      2   3
     / \
    4   5

Output: 3 (nodes 4, 5, and 3 are leaves)
```

**Example 3:**
```
Input: null

Output: 0
```

## Approach

### Recursive DFS
1. If node is null, return 0
2. If node is leaf (both children null), return 1
3. Otherwise, sum leaf counts from left and right subtrees

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Count leaf nodes recursively
 * Time: O(n), Space: O(h)
 */
function countLeafNodes(root) {
  if (root === null) {
    return 0;
  }

  // Check if current node is a leaf
  if (root.left === null && root.right === null) {
    return 1;
  }

  // Recursively count leaves in left and right subtrees
  return countLeafNodes(root.left) + countLeafNodes(root.right);
}

/**
 * Iterative using level-order traversal
 * Time: O(n), Space: O(w)
 */
function countLeafNodesIterative(root) {
  if (root === null) return 0;

  let count = 0;
  const queue = [root];

  while (queue.length > 0) {
    const node = queue.shift();

    // Check if leaf
    if (node.left === null && node.right === null) {
      count++;
    } else {
      if (node.left !== null) queue.push(node.left);
      if (node.right !== null) queue.push(node.right);
    }
  }

  return count;
}

/**
 * Iterative using stack (DFS)
 * Time: O(n), Space: O(h)
 */
function countLeafNodesDFS(root) {
  if (root === null) return 0;

  let count = 0;
  const stack = [root];

  while (stack.length > 0) {
    const node = stack.pop();

    if (node.left === null && node.right === null) {
      count++;
    } else {
      if (node.right !== null) stack.push(node.right);
      if (node.left !== null) stack.push(node.left);
    }
  }

  return count;
}
```

## Key Properties

- **Leaf Definition:** Both left and right children are null
- **Internal Nodes:** Nodes with at least one child
- **Minimum Leaves:** 1 (single node is a leaf)
- **Maximum Leaves:** ceil(n/2) for a full binary tree

## Complexity Analysis

- **Time:** O(n) - visit each node exactly once
- **Space (DFS):** O(h) - recursion or stack depth
- **Space (BFS):** O(w) - queue size equals maximum width
