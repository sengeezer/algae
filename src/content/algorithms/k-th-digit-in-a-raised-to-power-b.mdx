## Why It Surfaces

We need the k-th digit from right of `a^b`. Use:

- `mod = 10^k`
- `p = a^b mod mod` via fast exponentiation
- answer is `floor(p / 10^(k-1)) % 10`

## Worked Example

- `a = 3, b = 3, k = 1` -> `7` (from `27`)
- `a = 5, b = 2, k = 2` -> `2` (from `25`)

```js
function kthDigitInARaisedToPowerB(a, b, k) {
  if (!Number.isInteger(a) || !Number.isInteger(b) || !Number.isInteger(k) || b < 0 || k <= 0) {
    throw new RangeError('Expected integers with b >= 0 and k >= 1');
  }

  const bigA = BigInt(a);
  let exp = BigInt(b);
  const mod = 10n ** BigInt(k);

  let base = ((bigA % mod) + mod) % mod;
  let result = 1n;

  while (exp > 0n) {
    if (exp & 1n) {
      result = (result * base) % mod;
    }
    base = (base * base) % mod;
    exp >>= 1n;
  }

  const divisor = 10n ** BigInt(k - 1);
  return Number((result / divisor) % 10n);
}
```

## Common Pitfalls

- Computing `a^b` directly and overflowing.
- Forgetting that `k` is counted from the right.
- Not handling `b = 0` (`a^0 = 1`) correctly.
