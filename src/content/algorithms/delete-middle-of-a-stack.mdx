## Problem

Delete the middle element from a stack of size `n` using recursion.

## Approach

Recursively pop elements until reaching index `floor(n / 2)` from top recursion order, skip that item, then push back others.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function deleteMiddle(stack) {
  const target = Math.floor(stack.length / 2);

  function helper(depth) {
    if (stack.length === 0) return;

    const top = stack.pop();
    helper(depth + 1);

    if (depth !== target) {
      stack.push(top);
    }
  }

  helper(0);
}
```

```typescript
function deleteMiddle(stack: number[]): void {
  const target = Math.floor(stack.length / 2);

  function helper(depth: number): void {
    if (stack.length === 0) return;

    const top = stack.pop()!;
    helper(depth + 1);

    if (depth !== target) {
      stack.push(top);
    }
  }

  helper(0);
}
```
