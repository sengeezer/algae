## Why It Surfaces

For quadratic `ax^2 + bx + c`, compute

`D = b^2 - 4ac`

Then classify:

- `D > 0`: two distinct real roots
- `D = 0`: one repeated real root
- `D < 0`: no real roots

## Worked Example

- `a=20, b=30, c=10` -> `D=100`, two real roots
- `a=9, b=7, c=12` -> `D=-383`, no real roots

## Reference Implementations

<ExamplePair>

```js
function calculateTheDiscriminantValue(a, b, c) {
  if (![a, b, c].every(Number.isFinite)) {
    throw new TypeError('Expected finite numeric coefficients');
  }

  const discriminant = b * b - 4 * a * c;
  const nature = discriminant > 0
    ? 'Two Solutions'
    : discriminant === 0
      ? 'One Solution'
      : 'No Real Solutions';

  return { discriminant, nature };
}
```

## Common Pitfalls

- Using integer types and overflowing `b*b`.
- Forgetting the special case `D = 0`.
- Assuming equation is quadratic when `a = 0`.
