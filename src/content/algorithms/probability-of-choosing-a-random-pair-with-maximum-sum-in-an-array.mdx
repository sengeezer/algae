## Why It Surfaces

The pair with maximum sum is determined entirely by the largest values in the array. If the maximum value appears at least twice, every pair of maximum elements is optimal. Otherwise, each optimal pair combines the unique maximum with one copy of the second-largest value.

## Worked Example

For `A = [1, 2, 2, 3]`:

- Total unordered pairs: `4 * 3 / 2 = 6`
- The maximum value `3` appears once.
- The second maximum value `2` appears twice.
- Favorable pairs: `1 * 2 = 2`

So the probability is `2 / 6 = 1 / 3`.

```js
function combinationsOfTwo(count) {
  return (count * (count - 1)) / 2;
}

function probabilityOfChoosingARandomPairWithMaximumSumInAnArray(values) {
  if (!Array.isArray(values)) {
    throw new TypeError('Expected an array of numbers');
  }

  if (values.length < 2) {
    throw new RangeError('At least two elements are required');
  }

  let maximum = -Infinity;
  let maximumCount = 0;
  let secondMaximum = -Infinity;
  let secondMaximumCount = 0;

  for (const value of values) {
    if (typeof value !== 'number' || !Number.isFinite(value)) {
      throw new TypeError('All array elements must be finite numbers');
    }

    if (value > maximum) {
      secondMaximum = maximum;
      secondMaximumCount = maximumCount;
      maximum = value;
      maximumCount = 1;
    } else if (value === maximum) {
      maximumCount += 1;
    } else if (value > secondMaximum) {
      secondMaximum = value;
      secondMaximumCount = 1;
    } else if (value === secondMaximum) {
      secondMaximumCount += 1;
    }
  }

  const totalPairs = combinationsOfTwo(values.length);
  const favorablePairs =
    maximumCount >= 2
      ? combinationsOfTwo(maximumCount)
      : maximumCount * secondMaximumCount;

  return favorablePairs / totalPairs;
}
```

## Common Pitfalls

- Missing the repeated-maximum case and always multiplying by the second-maximum frequency.
- Treating pairs as ordered when the prompt uses `i < j`.
- Falling back to an unnecessary `O(n^2)` pair scan.
