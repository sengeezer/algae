## Why It Surfaces

Deficient-number questions are the simplest classification variant of proper-divisor sums. Once you can compute the sum of proper divisors efficiently, the rest is only a comparison.

## Worked Example

`21` is deficient because its proper divisors are `1`, `3`, and `7`, and their sum is `11`, which is less than `21`. By contrast, `12` is not deficient because its proper divisors sum to `16`.

## Reference Implementations

<ExamplePair>

```js
function sumProperDivisors(value) {
  if (value <= 1) {
    return 0;
  }

  let sum = 1;

  for (let divisor = 2; divisor * divisor <= value; divisor += 1) {
    if (value % divisor !== 0) {
      continue;
    }

    sum += divisor;
    const pairedDivisor = value / divisor;

    if (pairedDivisor !== divisor) {
      sum += pairedDivisor;
    }
  }

  return sum;
}

function deficientNumber(value) {
  if (!Number.isInteger(value) || value < 1) {
    throw new RangeError('Value must be a positive integer');
  }

  return sumProperDivisors(value) < value;
}

console.assert(deficientNumber(1) === true, '1 is deficient');
console.assert(deficientNumber(21) === true, '21 is deficient');
console.assert(deficientNumber(12) === false, '12 is not deficient');
```

## Follow-up Questions

- Return the deficiency amount instead of only a boolean answer.
- Reuse the same helper to classify numbers as deficient, perfect, or abundant.
- Explain why every prime number greater than `1` is deficient.

## Common Pitfalls

- Including the number itself in the proper-divisor sum.
- Forgetting that `1` has no proper divisors and is therefore deficient.
- Double-counting the square root divisor on perfect squares.
