## Problem

Given a binary search tree and a value to insert, insert the value into the BST while maintaining the BST property. Return the root of the modified tree.

### Examples

**Example 1:**
```
Input: 
       4
      / \
     2   7
    / \
   1   3
   
Value: 5

Output: 
       4
      / \
     2   7
    / \ /
   1  3 5
```

**Example 2:**
```
Input: 
     40
    /   \
   20   60
  / \   / \
 10 30 50 70
 
Value: 25

Output: 
     40
    /   \
   20   60
  / \   / \
 10 30 50 70
   /
  25
```

## Approach

### Recursive Insertion
1. If root is null, create and return a new node
2. If value < root value, recursively insert into left subtree
3. If value > root value, recursively insert into right subtree
4. If value equals root value, handle duplicate (typically skip or allow based on requirements)

### Iterative Insertion
Find the correct parent node, then attach the new node as its left or right child.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Recursive insertion
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) recursion depth
 */
function insertIntoBST(root, val) {
  if (root === null) {
    return new TreeNode(val);
  }

  if (val < root.val) {
    root.left = insertIntoBST(root.left, val);
  } else if (val > root.val) {
    root.right = insertIntoBST(root.right, val);
  }
  // If val === root.val, no insertion (skip duplicates)

  return root;
}

/**
 * Iterative insertion
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function insertIntoBSTIterative(root, val) {
  if (root === null) {
    return new TreeNode(val);
  }

  let current = root;

  while (true) {
    if (val < current.val) {
      if (current.left === null) {
        current.left = new TreeNode(val);
        break;
      }
      current = current.left;
    } else if (val > current.val) {
      if (current.right === null) {
        current.right = new TreeNode(val);
        break;
      }
      current = current.right;
    } else {
      // Duplicate value, no insertion
      break;
    }
  }

  return root;
}
```

## Key Properties

- **Leaf Node:** New nodes always inserted as leaves
- **Ordering Maintained:** BST property preserved after insertion
- **No Rebalancing:** Simple insertion without tree restructuring
- **Duplicates:** Typically skipped to maintain BST uniqueness

## Complexity Analysis

- **Time:** 
  - Average: O(log n) for balanced tree
  - Worst: O(n) for skewed tree
- **Space:**
  - Recursive: O(h) for recursion depth
  - Iterative: O(1) constant space
