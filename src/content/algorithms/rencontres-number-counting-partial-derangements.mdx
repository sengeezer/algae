## Overview

The Rencontres number `D(n, k)` counts permutations of `n` elements with exactly `k` fixed points.

A standard decomposition:

`D(n, k) = C(n, k) * !(n-k)`

where `!(m)` is the number of derangements of `m` elements.

## Approach

```js
function binomial(n, k) {
  if (k < 0 || k > n) return 0;
  k = Math.min(k, n - k);
  let res = 1;
  for (let i = 1; i <= k; i++) {
    res = (res * (n - k + i)) / i;
  }
  return Math.round(res);
}

function derangements(m) {
  if (m === 0) return 1;
  if (m === 1) return 0;
  let d0 = 1;
  let d1 = 0;
  for (let i = 2; i <= m; i++) {
    const d2 = (i - 1) * (d1 + d0);
    d0 = d1;
    d1 = d2;
  }
  return d1;
}

function rencontresNumber(n, k) {
  if (!Number.isInteger(n) || !Number.isInteger(k) || n < 0 || k < 0 || k > n) return -1;
  return binomial(n, k) * derangements(n - k);
}

console.assert(rencontresNumber(3, 0) === 2, "D(3,0)=2");
console.assert(rencontresNumber(3, 1) === 3, "D(3,1)=3");
console.assert(rencontresNumber(4, 2) === 6, "D(4,2)=6");
console.assert(rencontresNumber(7, 2) === 924, "D(7,2)=924");
```

## Notes

- `k = 0` reduces to pure derangements.
- This extends the derangement problem to exact fixed-point counts.
