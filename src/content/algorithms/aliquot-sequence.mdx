## Why It Surfaces

Aliquot sequences model repeated application of `sumProperDivisors(n)`. The process can:

- reach `0` (common for chains ending at `1 -> 0`), or
- enter a loop (for example, perfect numbers like `6` repeat immediately).

## Worked Example

- Starting at `10`: `10, 8, 7, 1, 0`
- Starting at `6`: `6, 6` and stop because a value repeats

```js
function aliquotSequence(start, maxSteps = 1000) {
  if (!Number.isInteger(start) || start <= 0) {
    throw new RangeError('Expected a positive integer start');
  }

  const sequence = [start];
  const seen = new Set([start]);
  let current = start;

  const sumProperDivisors = (n) => {
    if (n === 1) {
      return 0;
    }

    let sum = 1;
    const limit = Math.floor(Math.sqrt(n));
    for (let d = 2; d <= limit; d += 1) {
      if (n % d === 0) {
        sum += d;
        const pair = n / d;
        if (pair !== d) {
          sum += pair;
        }
      }
    }

    return sum;
  };

  for (let step = 0; step < maxSteps; step += 1) {
    const next = sumProperDivisors(current);
    sequence.push(next);

    if (next === 0 || seen.has(next)) {
      break;
    }

    seen.add(next);
    current = next;
  }

  return sequence;
}
```

## Common Pitfalls

- Treating `n` as a proper divisor of itself.
- Missing divisor pairs while summing.
- Forgetting to stop on repeated terms.
