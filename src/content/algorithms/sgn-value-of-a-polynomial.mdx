## Why It Surfaces

This prompt is the polynomial analogue of a generic sign function. Instead of classifying one number directly, you first evaluate the polynomial efficiently with Horner's method and then map the result to `-1`, `0`, or `1`.

## Worked Example

For coefficients `[2, -6, 2, -1]`, which represent `2x^3 - 6x^2 + 2x - 1`, evaluating at `x = 3` gives `5`, so the sign value is `1`.

```js
function evaluatePolynomialWithHorner(coefficients, x) {
  if (!Array.isArray(coefficients) || coefficients.length === 0) {
    throw new TypeError('coefficients must be a non-empty array');
  }

  if (coefficients.some((value) => typeof value !== 'number' || !Number.isFinite(value))) {
    throw new TypeError('coefficients must contain only finite numbers');
  }

  if (typeof x !== 'number' || !Number.isFinite(x)) {
    throw new TypeError('x must be a finite number');
  }

  let result = coefficients[0];

  for (let index = 1; index < coefficients.length; index += 1) {
    result = result * x + coefficients[index];
  }

  return result;
}

function sgnValueOfPolynomial(coefficients, x) {
  const value = evaluatePolynomialWithHorner(coefficients, x);

  if (value > 0) {
    return 1;
  }

  if (value < 0) {
    return -1;
  }

  return 0;
}
```

## Follow-up Questions

- Return the full evaluated value along with its sign.
- Explain why Horner's method avoids repeated exponentiation.
- Use the sign helper inside a bisection-style root search.

## Common Pitfalls

- Mixing ascending and descending coefficient order.
- Recomputing powers of x instead of folding the polynomial in one pass.
- Treating this as a duplicate of a generic `signum` helper even though the interesting part is the polynomial evaluation step.
