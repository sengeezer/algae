## Why It Surfaces

This is the array-search version of the Pythagorean triplet problem. The important observation is that after sorting the candidate side lengths, you can fix the largest value as `c` and use two pointers to search the smaller prefix for `a^2 + b^2 = c^2`.

## Worked Example

For `[3, 1, 4, 6, 5]`, sorting gives `[1, 3, 4, 5, 6]`. Fixing `5` as the candidate hypotenuse reveals `3^2 + 4^2 = 5^2`, so the array does contain a Pythagorean triplet.

function validatePositiveIntegerArray(values) {
  if (!Array.isArray(values)) {
    throw new TypeError('values must be an array');
  }

  if (!values.every((value) => Number.isInteger(value) && value > 0)) {
    throw new TypeError('values must contain only positive integers');
  }
}

function findPythagoreanTripletInArray(values) {
  validatePositiveIntegerArray(values);

  if (values.length < 3) {
    return null;
  }

  const sorted = [...values].sort((left, right) => left - right);

  for (let hypotenuseIndex = sorted.length - 1; hypotenuseIndex >= 2; hypotenuseIndex -= 1) {
    let left = 0;
    let right = hypotenuseIndex - 1;
    const target = sorted[hypotenuseIndex] * sorted[hypotenuseIndex];

    while (left < right) {
      const sumOfSquares = sorted[left] * sorted[left] + sorted[right] * sorted[right];

      if (sumOfSquares === target) {
        return [sorted[left], sorted[right], sorted[hypotenuseIndex]];
      }

      if (sumOfSquares < target) {
        left += 1;
      } else {
        right -= 1;
      }
    }
  }

  return null;
}

function threeSumPythagoreanTripletInAnArray(values) {
  return findPythagoreanTripletInArray(values) !== null;
}

const foundTriplet = findPythagoreanTripletInArray([3, 1, 4, 6, 5]);

## Follow-up Questions

## Common Pitfalls

- Checking every triple with three loops even after sorting would support a tighter search.
- Comparing raw side sums instead of squared values.
- Forgetting that the prompt uses positive integers, so zero and negative inputs should be rejected.
