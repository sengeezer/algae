## Problem

Given a relation matrix `knows[a][b]`, find the celebrity index, where a celebrity knows nobody and everyone knows the celebrity.

## Approach

Use two pointers to eliminate impossible candidates. Then verify the final candidate.

**Time Complexity**: O(n)
**Space Complexity**: O(1)

## Implementation

```javascript
function findCelebrity(knows) {
  const n = knows.length;
  let a = 0;
  let b = n - 1;

  while (a < b) {
    if (knows[a][b] === 1) {
      a++;
    } else {
      b--;
    }
  }

  const candidate = a;

  for (let i = 0; i < n; i++) {
    if (i === candidate) continue;
    if (knows[candidate][i] === 1 || knows[i][candidate] === 0) {
      return -1;
    }
  }

  return candidate;
}
```
