## Why It Surfaces

This is the standard probability model for repeated binary outcomes. Once you recognize fixed independent trials with constant success probability, the implementation reduces to `nCr * p^r * (1 - p)^(n - r)`.

## Worked Example

If a fair coin is tossed `3` times, the probability of getting exactly `2` heads is:

`C(3, 2) * 0.5^2 * 0.5^1 = 3 * 0.25 * 0.5 = 0.375`

function binomialCoefficient(n, r) {
  if (r < 0 || r > n) {
    return 0;
  }

  const choose = Math.min(r, n - r);
  let result = 1;

  for (let step = 1; step <= choose; step += 1) {
    result = (result * (n - choose + step)) / step;
  }

  return result;
}

function binomialDistributionInProbability(trials, successes, successProbability) {
  if (!Number.isInteger(trials) || trials < 0) {
    throw new RangeError('trials must be a non-negative integer');
  }

  if (!Number.isInteger(successes) || successes < 0 || successes > trials) {
    throw new RangeError('successes must be an integer between 0 and trials');
  }

  if (
    typeof successProbability !== 'number' ||
    !Number.isFinite(successProbability) ||
    successProbability < 0 ||
    successProbability > 1
  ) {
    throw new RangeError('successProbability must be between 0 and 1');
  }

  const failureProbability = 1 - successProbability;

  return (
    binomialCoefficient(trials, successes) *
    successProbability ** successes *
    failureProbability ** (trials - successes)
  );
}

  return result;

  trials: number,
  successes: number,
  successProbability: number,

  if (!Number.isInteger(trials) || trials < 0) {
    throw new RangeError('trials must be a non-negative integer');
  }

    throw new RangeError('successes must be an integer between 0 and trials');
  }

    throw new RangeError('successProbability must be between 0 and 1');

## Common Pitfalls

- Using the model when the trials are not independent or the success probability changes.
- Forgetting that the number of successes must lie between `0` and `n`.
- Expanding factorials directly instead of using a reduced multiplicative combination helper.
