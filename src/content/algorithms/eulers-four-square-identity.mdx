## Why It Surfaces

The source article demonstrates the identity by searching quadruples, but the mathematical heart of the problem is the closed-form construction itself. If two values are already known as sums of four squares, Euler's identity gives a representation of their product immediately.

## Worked Example

Take `30 = 1^2 + 2^2 + 3^2 + 4^2` and `4 = 1^2 + 1^2 + 1^2 + 1^2`. Applying the identity to `[1, 2, 3, 4]` and `[1, 1, 1, 1]` produces `[-8, 2, 6, 4]`, and `(-8)^2 + 2^2 + 6^2 + 4^2 = 120 = 30 * 4`.

function validateFourSquareInput(value, name) {
  if (
    !Array.isArray(value)
    || value.length !== 4
    || !value.every((entry) => Number.isInteger(entry))
  ) {
    throw new TypeError(`${name} must be an array of four integers`);
  }
}

function eulersFourSquareIdentity(left, right) {
  validateFourSquareInput(left, 'left');
  validateFourSquareInput(right, 'right');

  const [a1, a2, a3, a4] = left;
  const [b1, b2, b3, b4] = right;

  return [
    a1 * b1 - a2 * b2 - a3 * b3 - a4 * b4,
    a1 * b2 + a2 * b1 + a3 * b4 - a4 * b3,
    a1 * b3 - a2 * b4 + a3 * b1 + a4 * b2,
    a1 * b4 + a2 * b3 - a3 * b2 + a4 * b1,
  ];
}

function validateFourSquareInput(value: number[], name: string): void {
  if (value.length !== 4 || !value.every((entry) => Number.isInteger(entry))) {
    throw new TypeError(`${name} must be an array of four integers`);
  }
}

export function eulersFourSquareIdentity(
  left: [number, number, number, number],
  right: [number, number, number, number],
): [number, number, number, number] {
  validateFourSquareInput(left, 'left');
  validateFourSquareInput(right, 'right');

  const [a1, a2, a3, a4] = left;
  const [b1, b2, b3, b4] = right;

  return [
    a1 * b1 - a2 * b2 - a3 * b3 - a4 * b4,
    a1 * b2 + a2 * b1 + a3 * b4 - a4 * b3,
    a1 * b3 - a2 * b4 + a3 * b1 + a4 * b2,
    a1 * b4 + a2 * b3 - a3 * b2 + a4 * b1,
  ];
}

## Common Pitfalls

- Replacing the identity with brute-force search and missing the direct construction.
- Assuming the output coefficients must all be non-negative; the squares work regardless of sign.
- Mixing the signs in the four formulas and losing the norm-preserving property.
