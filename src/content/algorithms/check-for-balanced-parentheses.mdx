## Problem

Given a string containing brackets `()`, `{}`, and `[]`, determine whether the brackets are balanced.

## Approach

Push opening brackets. For every closing bracket, check whether the stack top is the corresponding opener.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function isBalanced(expr) {
  const stack = [];
  const pairs = {
    ')': '(',
    ']': '[',
    '}': '{'
  };

  for (const ch of expr) {
    if (ch === '(' || ch === '[' || ch === '{') {
      stack.push(ch);
    } else if (ch === ')' || ch === ']' || ch === '}') {
      if (stack.length === 0 || stack.pop() !== pairs[ch]) {
        return false;
      }
    }
  }

  return stack.length === 0;
}
```
