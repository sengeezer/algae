## Problem

Given a binary search tree, find and return the maximum value (rightmost node).

### Examples

**Example 1:**
```
Input: 
       4
      / \
     2   7
    / \   \
   1   3   9

Output: 9
```

**Example 2:**
```
Input: 
       10
       /
      5
     / \
    3   7

Output: 10
```

**Example 3:**
```
Input: Single node
       5

Output: 5
```

## Approach

### Iterative
Traverse right from the root until reaching a node with no right child.

### Recursive
If right child exists, recursively find maximum in right subtree. Otherwise, current node is maximum.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Iterative approach to find maximum
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function findMax(root) {
  if (root === null) return null;

  let current = root;
  while (current.right !== null) {
    current = current.right;
  }

  return current.val;
}

/**
 * Recursive approach to find maximum
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) recursion depth
 */
function findMaxRecursive(root) {
  if (root === null) return null;

  if (root.right === null) {
    return root.val;
  }

  return findMaxRecursive(root.right);
}

/**
 * Get the entire maximum node (not just value)
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function findMaxNode(root) {
  if (root === null) return null;

  let current = root;
  while (current.right !== null) {
    current = current.right;
  }

  return current;
}
```

## Key Properties

- **Always Right:** Maximum is always the rightmost reachable node
- **No Left Child Needed:** Maximum node may have a left subtree
- **In-order Successor:** Maximum in left subtree is predecessor to deletion

## Complexity Analysis

- **Time:** 
  - Average: O(log n) for balanced tree
  - Worst: O(n) for right-skewed tree
- **Space:**
  - Iterative: O(1) constant
  - Recursive: O(h) for recursion depth
