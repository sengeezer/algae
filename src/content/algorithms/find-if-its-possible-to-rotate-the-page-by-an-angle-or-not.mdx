## Why It Surfaces

The key is to avoid constructing rotation angles directly. A valid rotation around `b` needs equal radius from `b` to source and target points (`|ab| = |bc|`). Collinearity must be rejected because it implies a zero or 180-degree degenerate alignment for this mapping surface.

## Worked Example

- `a = (0, 1)`, `b = (1, 1)`, `c = (1, 0)` returns `true` (`Yes`) because a 90-degree rotation works.
- `a = (1, 1)`, `b = (0, 0)`, `c = (1000, 1000)` returns `false` (`No`) because distances from `b` are unequal.

## Reference Implementations

<ExamplePair>

```js
function findIfItsPossibleToRotateThePageByAnAngleOrNot(a, b, c) {
  function squaredDistance(first, second) {
    const dx = first.x - second.x;
    const dy = first.y - second.y;
    return dx * dx + dy * dy;
  }

  const distanceAB = squaredDistance(a, b);
  const distanceBC = squaredDistance(b, c);
  if (distanceAB !== distanceBC || distanceAB === 0) {
    return false;
  }

  const cross = (a.x - b.x) * (c.y - b.y) - (a.y - b.y) * (c.x - b.x);
  return cross !== 0;
}
```

```ts
type Point = { x: number; y: number };

export function findIfItsPossibleToRotateThePageByAnAngleOrNot(a: Point, b: Point, c: Point): boolean {
  function squaredDistance(first: Point, second: Point): number {
    const dx = first.x - second.x;
    const dy = first.y - second.y;
    return dx * dx + dy * dy;
  }

  const distanceAB = squaredDistance(a, b);
  const distanceBC = squaredDistance(b, c);
  if (distanceAB !== distanceBC || distanceAB === 0) {
    return false;
  }

  const cross = (a.x - b.x) * (c.y - b.y) - (a.y - b.y) * (c.x - b.x);
  return cross !== 0;
}
```

## Common Pitfalls

- Comparing floating distances instead of squared integer distances.
- Forgetting to reject the degenerate case where `a` and `b` coincide.
- Accepting collinear triples that do not represent the intended rotation surface.
