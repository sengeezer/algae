## Why It Surfaces

This prompt appears when a geometric optimization is reduced to one degree of freedom. Once you parametrize the line, the sum of distances becomes a convex function of one variable, which is exactly where ternary search is effective.

## Worked Example

For points `(0, 0)` and `(2, 0)` with line `y = 0` (i.e., `0x + 1y + 0 = 0`), any point on the segment between them is optimal and the minimum total distance is `2`.

```js
function optimumLocationOfPointToMinimizeTotalDistance(points, line) {
  if (!Array.isArray(points) || points.length === 0) {
    throw new RangeError("Expected at least one point");
  }
  if (!Number.isFinite(line.a) || !Number.isFinite(line.b) || !Number.isFinite(line.c) || (line.a === 0 && line.b === 0)) {
    throw new RangeError("Expected a valid line ax + by + c = 0");
  }

  const basePoint = Math.abs(line.b) > 1e-12 ? { x: 0, y: -line.c / line.b } : { x: -line.c / line.a, y: 0 };
  const direction = { x: line.b, y: -line.a };
  const directionNormSquared = direction.x * direction.x + direction.y * direction.y;

  const parameters = points.map((point) =>
    ((point.x - basePoint.x) * direction.x + (point.y - basePoint.y) * direction.y) / directionNormSquared,
  );
  let low = Math.min(...parameters) - 1000;
  let high = Math.max(...parameters) + 1000;

  function totalDistance(parameter) {
    const x = basePoint.x + direction.x * parameter;
    const y = basePoint.y + direction.y * parameter;
    return points.reduce((sum, point) => sum + Math.hypot(x - point.x, y - point.y), 0);
  }

  for (let iteration = 0; iteration < 120; iteration += 1) {
    const first = low + (high - low) / 3;
    const second = high - (high - low) / 3;
    if (totalDistance(first) <= totalDistance(second)) {
      high = second;
    } else {
      low = first;
    }
  }

  const parameter = (low + high) / 2;
  const point = {
    x: basePoint.x + direction.x * parameter,
    y: basePoint.y + direction.y * parameter,
  };

  return {
    point,
    totalDistance: totalDistance(parameter),
  };
}
```

## Follow-up Questions

- Why is ternary search valid for this objective on a line?
- How would you adapt this to Manhattan distance instead of Euclidean distance?
- What changes if the feasible region is a segment instead of an infinite line?

## Common Pitfalls

- Applying binary search to a non-monotonic objective.
- Forgetting to validate that the line is not degenerate (`a = b = 0`).
- Picking a search range that does not cover useful projections of input points.
