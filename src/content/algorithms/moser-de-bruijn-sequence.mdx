## Why It Surfaces

The Moser-de Bruijn sequence consists of numbers representable as sums of distinct powers of 4. GeeksforGeeks highlights the recurrence:

- `S(2n) = 4 * S(n)`
- `S(2n + 1) = 4 * S(n) + 1`
- `S(0) = 0`

This supports direct iterative generation of the first `n` terms.

## Worked Example

- First 10 terms: `0, 1, 4, 5, 16, 17, 20, 21, 64, 65`
- For `n = 5`, output is `0 1 4 5 16`

## Reference Implementations

<ExamplePair>

```js
function moserDeBruijnSequence(count) {
  if (!Number.isInteger(count) || count < 0) {
    throw new RangeError('Expected a non-negative integer count');
  }

  if (count === 0) {
    return [];
  }

  const values = new Array(count).fill(0);
  values[0] = 0;

  for (let i = 1; i < count; i += 1) {
    values[i] = i % 2 === 0 ? 4 * values[Math.floor(i / 2)] : 4 * values[Math.floor(i / 2)] + 1;
  }

  return values;
}
```

## Common Pitfalls

- Mixing index recurrence with value recurrence incorrectly.
- Off-by-one errors around `count` versus largest index.
- Returning `count` terms when `count = 0` without a guard.
