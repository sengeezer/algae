## Why It Surfaces

For divisibility by 11, the useful invariant is alternating place values: `10^k mod 11` alternates between `1` and `-1`. That makes the modulo test equivalent to checking if the difference between alternating digit sums is divisible by 11.

## Worked Example

- For `121`, alternating sums are `(1 + 1)` and `(2)`, difference `0`, so it is divisible by 11.
- For `123456789`, alternating sums differ by `5`, so it is not divisible by 11.

## Reference Implementations

<ExamplePair>

```js
function checkIfALargeNumberIsDivisibleBy11OrNot(value) {
  const text = String(value).trim();
  const normalized = text.startsWith('+') || text.startsWith('-') ? text.slice(1) : text;

  if (normalized.length === 0 || !/^\d+$/.test(normalized)) {
    throw new TypeError("Expected a decimal integer string or integer-like value");
  }

  let alternatingDifference = 0;
  for (let index = 0; index < normalized.length; index += 1) {
    const digit = normalized.charCodeAt(index) - 48;
    alternatingDifference += index % 2 === 0 ? digit : -digit;
  }

  return Math.abs(alternatingDifference) % 11 === 0;
}
```

## Common Pitfalls

- Summing all digits instead of alternating signs.
- Forgetting to take absolute value before final modulus test.
- Treating non-digit input as valid numeric strings.
