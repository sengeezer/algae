## Why It Surfaces

Tetrahedral numbers extend the figurate-number family, representing 3D structures (tetrahedral stacks). They appear in combinatorial counting, relationship exploration between figurate sequences, and geometric interpretation of number patterns.

## Worked Example

The first five tetrahedral numbers are: 1, 4, 10, 20, and 35. The 4th tetrahedral number is 20 because it is the sum of the first four triangular numbers: 1 + 3 + 6 + 10 = 20.

function tetrahedralNumber(n) {
  if (!Number.isInteger(n) || n < 1) {
    throw new RangeError('n must be a positive integer');
  }

  return (n * (n + 1) * (n + 2)) / 6;
}

function generateTetrahedralNumbers(limit) {
  if (!Number.isInteger(limit) || limit < 1) {
    throw new RangeError('Limit must be a positive integer');
  }

  const tetrahedral = [];
  let n = 1;

  while (true) {
    const tetra = tetrahedralNumber(n);
    if (tetra > limit) {
      break;
    }
    tetrahedral.push(tetra);
    n += 1;
  }

  return tetrahedral;
}

function tetrahedralNumberAsTriangularSum(n) {
  if (!Number.isInteger(n) || n < 1) {
    throw new RangeError('n must be a positive integer');
  }

  let sum = 0;

  for (let i = 1; i <= n; i += 1) {
    sum += (i * (i + 1)) / 2;
  }

  return sum;
}

console.assert(tetrahedralNumber(1) === 1, 'T(1) = 1');
console.assert(tetrahedralNumber(4) === 20, 'T(4) = 20');
console.assert(tetrahedralNumber(5) === 35, 'T(5) = 35');
console.assert(
  JSON.stringify(generateTetrahedralNumbers(100)) ===
    JSON.stringify([1, 4, 10, 20, 35, 56, 84]),
  'Generated tetrahedral numbers up to 100'
);
console.assert(
  tetrahedralNumberAsTriangularSum(4) === tetrahedralNumber(4),
  'Tetrahedral by formula equals sum of triangular'
);

## Key Insights

- The formula T(n) = n times (n+1) times (n+2) divided by 6 provides constant-time lookup.
- Tetrahedral numbers are cumulative sums of consecutive triangular numbers.
- Geometrically, tetrahedral numbers count objects stacked in a pyramid with n layers.
- The combinatorial interpretation: tetrahedral numbers equal the binomial coefficient C(n+2, 3).
