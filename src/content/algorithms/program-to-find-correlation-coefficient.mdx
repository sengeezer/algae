## Why It Surfaces

For arrays `X` and `Y` of length `n`, Pearson's correlation coefficient uses:

- numerator: `n * sumXY - sumX * sumY`
- denominator: `sqrt((n * sumX2 - sumX^2) * (n * sumY2 - sumY^2))`
- result: `numerator / denominator`

This requires only five running sums.

## Worked Example

- `X = [15, 18, 21, 24, 27]`
- `Y = [25, 25, 27, 31, 32]`
- `r ≈ 0.953463`

```js
function programToFindCorrelationCoefficient(X, Y) {
  if (!Array.isArray(X) || !Array.isArray(Y) || X.length !== Y.length || X.length === 0) {
    throw new RangeError('Expected two non-empty arrays of equal length');
  }

  const n = X.length;
  let sumX = 0;
  let sumY = 0;
  let sumXY = 0;
  let sumX2 = 0;
  let sumY2 = 0;

  for (let i = 0; i < n; i += 1) {
    sumX += X[i];
    sumY += Y[i];
    sumXY += X[i] * Y[i];
    sumX2 += X[i] * X[i];
    sumY2 += Y[i] * Y[i];
  }

  const numerator = n * sumXY - sumX * sumY;
  const denominator = Math.sqrt((n * sumX2 - sumX * sumX) * (n * sumY2 - sumY * sumY));

  if (denominator === 0) {
    throw new RangeError('Correlation is undefined when variance is zero');
  }

  return numerator / denominator;
}
```
