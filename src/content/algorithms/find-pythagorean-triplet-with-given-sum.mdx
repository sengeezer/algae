## Why It Surfaces

This problem looks similar to a generic triplet generator, but the fixed target sum changes the search shape. Once `a` and `b` are chosen, `c` is already determined as `target - a - b`, so the real task is to scan the remaining pairs efficiently and keep every match.

## Worked Example

For `target = 60`, the valid integer right-triangle triples are `[10, 24, 26]` and `[15, 20, 25]`. Both satisfy `a + b + c = 60` and `a^2 + b^2 = c^2`.

## Reference Implementations

<ExamplePair>

```js
function findPythagoreanTripletWithGivenSum(target) {
  if (!Number.isInteger(target) || target < 3) {
    throw new RangeError('target must be an integer at least 3');
  }

  const triplets = [];

  for (let a = 1; a < target / 3; a += 1) {
    for (let b = a + 1; b < (target - a) / 2; b += 1) {
      const c = target - a - b;

      if (a * a + b * b === c * c) {
        triplets.push([a, b, c]);
      }
    }
  }

  return triplets;
}

function hasPythagoreanTripletWithGivenSum(target) {
  return findPythagoreanTripletWithGivenSum(target).length > 0;
}

const perimeterSixtyTriplets = findPythagoreanTripletWithGivenSum(60);
console.assert(

  'sum 60 should yield exactly two triplets'
);
console.assert(
  hasPythagoreanTripletWithGivenSum(4) === false,
  'sum 4 should not yield any triplet'
);
```

## Common Pitfalls

- Using three nested loops even though `c` is fixed once `a` and `b` are known.
- Forgetting the ordering constraint `a < b < c`, which can create duplicates.
- Returning a single product when the prompt asks for every valid triplet.
