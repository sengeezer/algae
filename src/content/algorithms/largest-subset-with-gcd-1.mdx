## Why It Surfaces

The trap is to think this needs subset enumeration. The key property is monotonic: if some subset has gcd `1`, adding more elements keeps gcd at `1`, so the largest such subset is the whole array.

## Worked Example

- For `[2, 3, 5]`, overall gcd is `1`, so the answer is the full size `3`.
- For `[3, 18, 12]`, overall gcd is `3`, so no subset can reach gcd `1`, and the answer is `-1`.

function gcd(left, right) {
  let a = Math.abs(left);
  let b = Math.abs(right);

  while (b !== 0) {
    [a, b] = [b, a % b];
  }

  return a;
}

function largestSubsetWithGcd1(values) {
  if (!Array.isArray(values) || values.length === 0) {
    throw new RangeError("Expected a non-empty array of positive integers");
  }

  let runningGcd = 0;
  for (const value of values) {
    if (!Number.isInteger(value) || value < 1) {
      throw new RangeError("Array elements must be positive integers");
    }

    runningGcd = gcd(runningGcd, value);
    if (runningGcd === 1) {
      return values.length;
    }
  }

  return -1;
}

## Common Pitfalls

- Attempting subset generation or backtracking, which is unnecessary.
- Returning `0` instead of `-1` when no subset with gcd `1` exists.
- Ignoring early exit when the running gcd first becomes `1`.
