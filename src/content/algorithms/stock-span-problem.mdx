## Problem

Given daily stock prices, return the span for each day where span is the count of consecutive days (ending today) with price less than or equal to today's price.

## Approach

Maintain a stack of indices with strictly greater prices than upcoming elements.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function stockSpan(prices) {
  const n = prices.length;
  const span = new Array(n).fill(1);
  const stack = [];

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && prices[stack[stack.length - 1]] <= prices[i]) {
      stack.pop();
    }

    span[i] = stack.length === 0 ? i + 1 : i - stack[stack.length - 1];
    stack.push(i);
  }

  return span;
}
```
