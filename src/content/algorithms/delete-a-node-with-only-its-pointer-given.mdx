## Problem

Delete a node from a singly linked list when only a pointer/reference to that node is provided and head is unavailable.

## Approach

Copy data from `node.next` into `node`, then bypass `node.next`.

This effectively removes the successor while making the target node appear deleted.

**Time Complexity**: O(1)
**Space Complexity**: O(1)

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

function deleteNodeWithOnlyPointerGiven(node) {
  if (node === null || node.next === null) {
    throw new Error("Cannot delete tail or null node using this method");
  }

  node.data = node.next.data;
  node.next = node.next.next;
}
```

```typescript
class Node {
  data: number;
  next: Node | null;

  constructor(data: number) {
    this.data = data;
    this.next = null;
  }
}

function deleteNodeWithOnlyPointerGiven(node: Node | null): void {
  if (node === null || node.next === null) {

  node.data = node.next.data;
  node.next = node.next.next;
}
```
