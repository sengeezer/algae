## Why It Surfaces

This is the subset-average version of contribution counting. For any fixed subset size `k`, each element appears in exactly `C(n - 1, k - 1)` subsets of that size, so the total contribution from all size-`k` averages is `sum(values) * C(n - 1, k - 1) / k`. Summing across all `k` gives the compact identity `sum(values) * (2^n - 1) / n`.

## Worked Example

For `[2, 3, 5]`, the non-empty subsets have averages `2`, `3`, `5`, `2.5`, `3.5`, `4`, and `10 / 3`, whose total is `70 / 3`. The shortcut produces the same value with `(10 * (2^3 - 1)) / 3 = 70 / 3`.

## Reference Implementations

<ExamplePair>

```js
function sumOfAverageOfAllSubsets(values) {
  if (!Array.isArray(values)) {
    throw new TypeError('values must be an array');
  }

  if (values.length === 0) {
    return 0;
  }

  const total = values.reduce((sum, value) => {
    if (!Number.isFinite(value)) {
      throw new TypeError('values must contain only finite numbers');
    }

    return sum + value;
  }, 0);

  return (total * (2 ** values.length - 1)) / values.length;
}
```

## Follow-up Questions

- Derive the identity by grouping subsets by size `k`.
- Return the answer as a reduced fraction instead of a floating-point number.
- Compare this with the simpler subset-sum aggregation that uses `2^(n - 1)` directly.

## Common Pitfalls

- Including the empty subset even though its average is undefined.
- Enumerating all subsets when the prompt only asks for the final aggregate.
- Forgetting that the final multiplier is `(2^n - 1) / n`, not just `2^(n - 1)`.
