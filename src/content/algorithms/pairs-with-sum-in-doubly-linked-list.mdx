## Problem

Given a sorted doubly linked list and an integer target, return all unique pairs of node values that sum to target.

## Approach

Use two pointers:

- `left` starts at head
- `right` starts at tail

If `left.data + right.data` is smaller than target, move `left` forward. If larger, move `right` backward. If equal, record pair and move both inward.

**Time Complexity**: O(n)
**Space Complexity**: O(1) auxiliary

## Implementation

```javascript
class Node {
  constructor(data) {
    this.data = data;
    this.prev = null;
    this.next = null;
  }
}

function pairsWithSumInDoublyLinkedList(head, target) {
  const pairs = [];

  if (head === null) {
    return pairs;
  }

  let left = head;
  let right = head;

  while (right.next !== null) {
    right = right.next;
  }

  while (left !== null && right !== null && left !== right && left.prev !== right) {
    const sum = left.data + right.data;

    if (sum === target) {
      pairs.push([left.data, right.data]);
      left = left.next;
      right = right.prev;
    } else if (sum < target) {
      left = left.next;
    } else {
      right = right.prev;
    }
  }

  return pairs;
}
```
