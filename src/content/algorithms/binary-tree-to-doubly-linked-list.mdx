## Problem

Given a Binary Search Tree (BST), convert it into a Doubly Linked List where:
- The left pointer of a tree node becomes the previous pointer of a DLL node.
- The right pointer of a tree node becomes the next pointer of a DLL node.
- The result is a doubly linked list in sorted (in-order) order.

## Approach

1. Perform in-order traversal of the BST.
2. During traversal, maintain a pointer to the last processed node.
3. Link the current node's left to the previous node and right to the next node.
4. Terminate when reaching the leftmost node (head) and rightmost node (tail).

**Time Complexity**: O(n) for single in-order pass
**Space Complexity**: O(h) for recursion stack

## Implementation

```javascript
class TreeNode {
  constructor(data) {
    this.data = data;
    this.left = null;
    this.right = null;
  }
}

function bstToDoublyLinkedList(root) {
  let head = null;
  let prev = null;

  function inOrder(node) {
    if (node === null) return;

    inOrder(node.left);

    // Convert tree node to DLL node
    if (prev === null) {
      head = node;
    } else {
      prev.right = node;
      node.left = prev;
    }
    prev = node;

    inOrder(node.right);
  }

  inOrder(root);
  return head;
}
```
