## Problem

For every element in an array, output the previous element that is smaller than it; if none, output `-1`.

## Approach

Keep a monotonic increasing stack of previous candidates.

**Time Complexity**: O(n)
**Space Complexity**: O(n)

## Implementation

```javascript
function previousSmallerElement(arr) {
  const stack = [];
  const result = [];

  for (const x of arr) {
    while (stack.length > 0 && stack[stack.length - 1] >= x) {
      stack.pop();
    }

    result.push(stack.length === 0 ? -1 : stack[stack.length - 1]);
    stack.push(x);
  }

  return result;
}
```
