## Problem

Given a binary search tree and a target value, search for the target and return the subtree rooted with that node if found, otherwise return null.

### Examples

**Example 1:**
```
Input: 
       4
      / \
     2   7
    / \
   1   3
   
Target: 2

Output: 
       2
      / \
     1   3
```

**Example 2:**
```
Input: 
       4
      / \
     2   7
    / \
   1   3
   
Target: 5

Output: null
```

## Approach

### Recursive Search
1. If root is null, return null (not found)
2. If target equals root value, return root
3. If target is less than root value, search left subtree
4. If target is greater than root value, search right subtree

### Iterative Search
Use a pointer to traverse the tree, moving left or right based on comparisons with target.

## Solution

### JavaScript

```javascript
// Definition for a binary tree node
class TreeNode {
  constructor(val = 0, left = null, right = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

/**
 * Recursive search
 * Time: O(log n) average, O(n) worst case
 * Space: O(h) recursion depth
 */
function searchBST(root, target) {
  if (root === null) return null;

  if (target === root.val) {
    return root;
  } else if (target < root.val) {
    return searchBST(root.left, target);
  } else {
    return searchBST(root.right, target);
  }
}

/**
 * Iterative search
 * Time: O(log n) average, O(n) worst case
 * Space: O(1)
 */
function searchBSTIterative(root, target) {
  let current = root;

  while (current !== null) {
    if (target === current.val) {
      return current;
    } else if (target < current.val) {
      current = current.left;
    } else {
      current = current.right;
    }
  }

  return null;
}
```

## Key Properties

- **Pruning:** Eliminates entire subtrees based on comparison
- **Balanced BST:** Guarantees O(log n) search performance
- **Unbalanced BST:** Degrades to O(n) in worst case (skewed tree)
- **Ordering:** Left subtree < node < right subtree

## Complexity Analysis

- **Time:** 
  - Average: O(log n) for balanced tree
  - Worst: O(n) for skewed tree
- **Space:**
  - Recursive: O(h) for recursion depth
  - Iterative: O(1) constant space
