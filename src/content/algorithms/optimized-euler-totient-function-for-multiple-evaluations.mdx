## Why It Surfaces

The single-value totient formulas are enough for one input, but they waste work when the same program must answer the question thousands of times. The optimization is to sieve primes once up to the largest square root you will need and then reuse that prime list for every totient evaluation.

## Worked Example

For queries `[5, 6, 10, 13]`, build the shared prime list `[2, 3]` because `sqrt(13)` is less than `4`. Then evaluate each totient with the same primes: `phi(5) = 4`, `phi(6) = 2`, `phi(10) = 4`, and `phi(13) = 12`.

function sievePrimes(limit) {
  if (limit < 2) {
    return [];
  }

  const isComposite = new Array(limit + 1).fill(false);
  const primes = [];

  for (let value = 2; value <= limit; value += 1) {
    if (!isComposite[value]) {
      primes.push(value);

      if (value <= Math.floor(limit / value)) {
        for (let multiple = value * value; multiple <= limit; multiple += value) {
          isComposite[multiple] = true;
        }
      }
    }
  }

  return primes;
}

function phiWithPrimeList(value, primes) {
  let remaining = value;
  let result = value;

  for (const prime of primes) {
    if (prime * prime > remaining) {
      break;
    }

    if (remaining % prime !== 0) {
      continue;
    }

    while (remaining % prime === 0) {
      remaining = Math.floor(remaining / prime);
    }

    result -= Math.floor(result / prime);
  }

  if (remaining > 1) {
    result -= Math.floor(result / remaining);
  }

  return result;
}

function optimizedEulerTotientMultipleEvaluations(values) {
  if (!Array.isArray(values) || values.length === 0) {
    return [];
  }

  if (!values.every((value) => Number.isInteger(value) && value >= 1)) {
    throw new RangeError('Values must be positive integers');
  }

  const maxValue = Math.max(...values);
  const primes = sievePrimes(Math.floor(Math.sqrt(maxValue)));

  return values.map((value) => phiWithPrimeList(value, primes));
}

function phiWithPrimeList(value: number, primes: number[]): number {
  let remaining = value;
  let result = value;

  for (const prime of primes) {
    if (prime * prime > remaining) {
      break;
    }

    if (remaining % prime !== 0) {
      continue;

      remaining = Math.floor(remaining / prime);
    }

    result -= Math.floor(result / remaining);
  }

  return result;
}

## Follow-up Questions

- Cache the prime list across multiple batches of queries instead of rebuilding it every call.
- Compare this repeated-query approach against the full `phi[1..n]` sieve table.
- Extend the same precomputation to support repeated coprime-count or divisor-count queries.

## Common Pitfalls

- Sieving fresh primes for every input value and losing the whole repeated-query win.
- Iterating all integers up to `sqrt(n)` instead of only the precomputed primes.
- Forgetting the leftover prime factor after the prime loop ends.
