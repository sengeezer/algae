## Problem

Design a data structure that supports `push`, `pop`, `top`, and `getMin` in O(1) time.

## Approach

Use two stacks:
- `values` holds all elements.
- `mins` holds current minimum at each depth.

**Time Complexity**: O(1) per operation
**Space Complexity**: O(n)

## Implementation

```javascript
class MinStack {
  constructor() {
    this.values = [];
    this.mins = [];
  }

  push(x) {
    this.values.push(x);
    if (this.mins.length === 0) this.mins.push(x);
    else this.mins.push(Math.min(x, this.mins[this.mins.length - 1]));
  }

  pop() {
    if (this.values.length === 0) return null;
    this.mins.pop();
    return this.values.pop();
  }

  top() {
    if (this.values.length === 0) return null;
    return this.values[this.values.length - 1];
  }

  getMin() {
    if (this.mins.length === 0) return null;
    return this.mins[this.mins.length - 1];
  }
}
```

```typescript
class MinStack {
  private values: number[] = [];
  private mins: number[] = [];

  push(x: number): void {
    this.values.push(x);
    if (this.mins.length === 0) this.mins.push(x);
    else this.mins.push(Math.min(x, this.mins[this.mins.length - 1]));
  }

  pop(): number | null {
    if (this.values.length === 0) return null;
    this.mins.pop();
    return this.values.pop()!;
  }

  top(): number | null {
    if (this.values.length === 0) return null;
    return this.values[this.values.length - 1];
  }

  getMin(): number | null {
    if (this.mins.length === 0) return null;
    return this.mins[this.mins.length - 1];
  }
}
```
