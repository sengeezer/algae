## Why It Surfaces

The sequence is defined by:

`P(n) = P(P(n - 1)) + P(n - P(n - 1))`, with `P(1)=1`, `P(2)=1`.

Because terms reuse previous terms as indices, bottom-up DP is the reliable approach.

## Worked Example

- Sequence prefix: `1, 1, 2, 2, 3, 4, 4, 4, 5, 6, 7, 7, ...`
- `P(10) = 6`

## Reference Implementations

<ExamplePair>

```js
function newmanConwaySequence(n) {
  if (!Number.isInteger(n) || n <= 0) {
    throw new RangeError('Expected a positive integer n');
  }

  if (n <= 2) {
    return 1;
  }

  const dp = new Array(n + 1).fill(0);
  dp[1] = 1;
  dp[2] = 1;

  for (let i = 3; i <= n; i += 1) {
    dp[i] = dp[dp[i - 1]] + dp[i - dp[i - 1]];
  }

  return dp[n];
}
```

## Common Pitfalls

- Forgetting base terms `P(1)` and `P(2)`.
- Using 0-based indexing without adjusting the recurrence.
- Recursive implementations that blow up due to repeated work.
