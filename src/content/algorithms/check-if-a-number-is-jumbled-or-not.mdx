## Why It Surfaces

A number is jumbled if every adjacent digit differs by at most 1. This is a direct digit-adjacency scan.

## Worked Example

- `6765` -> `true`
- `1223` -> `true`
- `1235` -> `false`

## Reference Implementations

<ExamplePair>

```js
function checkIfANumberIsJumbledOrNot(num) {
  if (!Number.isInteger(num) || num < 0) {
    throw new RangeError('Expected a non-negative integer');
  }

  if (num < 10) {
    return true;
  }

  let n = num;
  while (n >= 10) {
    const d1 = n % 10;
    const d2 = Math.floor(n / 10) % 10;
    if (Math.abs(d1 - d2) > 1) {
      return false;
    }
    n = Math.floor(n / 10);
  }

  return true;
}
```
