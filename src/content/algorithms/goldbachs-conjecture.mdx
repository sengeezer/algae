## Why It Surfaces

Goldbach's conjecture turns into a practical prime-partition problem as soon as the prompt asks you to verify or construct prime pairs for one even number. The implementation goal is not to prove the conjecture for all inputs, but to find the prime addends that witness a concrete instance.

## Worked Example

For `26`, the valid Goldbach partitions are `[3, 23]`, `[7, 19]`, and `[13, 13]`. A sieve gives constant-time primality checks, so you can scan `left` from `2` through `13` and test whether `26 - left` is also prime.

function sieve(limit) {
  const isPrime = new Array(limit + 1).fill(true);

  if (limit >= 0) {
    isPrime[0] = false;
  }

  if (limit >= 1) {
    isPrime[1] = false;
  }

  for (let value = 2; value * value <= limit; value += 1) {
    if (!isPrime[value]) {
      continue;
    }

    for (let multiple = value * value; multiple <= limit; multiple += value) {
      isPrime[multiple] = false;
    }
  }

  return isPrime;
}

function goldbachPartitions(evenNumber) {
  if (!Number.isInteger(evenNumber) || evenNumber < 4 || evenNumber % 2 !== 0) {
    throw new RangeError('Value must be an even integer at least 4');
  }

  const isPrime = sieve(evenNumber);
  const partitions = [];

  for (let left = 2; left <= Math.floor(evenNumber / 2); left += 1) {
    const right = evenNumber - left;
    if (isPrime[left] && isPrime[right]) {
      partitions.push([left, right]);
    }
  }

  return partitions;
}

console.assert(JSON.stringify(goldbachPartitions(26)) === JSON.stringify([[3, 23], [7, 19], [13, 13]]), 'Goldbach partitions of 26');

## Follow-up Questions

- Return only the first partition instead of every valid pair.
- Reuse one sieve to answer Goldbach queries for many even numbers below the same limit.
- Count Goldbach partitions instead of materializing them.

## Common Pitfalls

- Accepting odd inputs even though the constructive prompt is about even integers greater than `2`.
- Scanning the full `2..n-2` range and producing each partition twice.
- Rechecking primality with trial division for each complement instead of reusing a sieve.
